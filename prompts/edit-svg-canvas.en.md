## Compatibility note

Visual editing requires the installed skill package, Python 3.10+, a local browser/server, and a verified Method Draw cache or first-use network access. Text-only chats can prepare a manual handoff but cannot launch this editor.

## Instructions for the AI

# Edit a design visually

Open the current design in a local Method Draw editor. Let the user edit text
and move materials, then click **Save and finish / 儲存並完成** to save a new SVG
revision directly into the task's output folder. This works independently of
Toastmasters, Codex panels, and any particular document task.

## Recognize the user's intent

Requests such as “let me change this myself”, “I want to edit the poster”,
“move the photo”, “我要自己改文字”, “我想手動編輯”, and “讓我調整位置” are enough.
Do not ask the user to name a file format or editor. Find the current task's
editable source first. If several plausible designs remain, ask which one.
For a plain instruction such as “change the title to X”, make the requested edit
directly unless the user wants a visual editing session.

If only a flattened image exists, explain that text and materials must first be
reconstructed as separate elements; do not promise that a PNG becomes editable
merely by putting it inside an SVG.

## Launch and return

Resolve `scripts/edit_svg.py` relative to this installed skill, not the task's
working directory. Read runtime instructions (bundled in this prompt) for
cache preparation, fonts, session lifecycle, and recovery.

```sh
python3 /absolute/path/to/edit-svg-canvas/scripts/edit_svg.py launch /absolute/path/to/design.svg --output-dir /absolute/path/to/task/output --open
```

Run this as a persistent process using the host's supported background/session
mechanism. Keep its process alive while the user edits. Open the printed
`editor_url` in an available browser and retain the printed `session_json` path
in the conversation. In Codex a browser panel can show this URL; a normal browser
is the baseline for WorkBuddy and other hosts. Explain: “Edit the text or drag
items. Click Save and finish, then return here and say continue.”

When the user returns, run:

```sh
python3 /absolute/path/to/edit-svg-canvas/scripts/edit_svg.py status /absolute/path/to/session.json
```

Only `state: complete` plus successful hash verification establishes a finished
handoff. Use `saved_path` as the new source; never regenerate from a stale build
script that would discard the user's edits. An editing state means no finish
has been saved yet. Stop only this session's server after handoff or cancellation.

Saving returns an SVG; the caller decides whether to render PNG/PDF or resume
another task. For posters, rerender the exact saved file and repeat the caller's
visual, protected-asset, QR, and independent review requirements. Saving does not
automatically message an agent, call an image model, or publish anything.

## Limits and truthfulness

The launcher needs Python 3.10+, permission to bind a loopback port, and first-use
network access or the verified archive/cache. It preserves originals and writes
new revisions. Unsupported active/external SVG content is rejected explicitly.
Embedded raster artwork stays raster; outlined text cannot be edited as words.
Inspect the imported design and final saved rendering for font/layout changes.
If a host cannot launch a server, offer a manual handoff and identify the missing
capability. A text-only portable prompt does not contain the executable package.
Do not claim WorkBuddy discovery or successful editing without testing it there.

# Local Method Draw runtime

Run Python 3.10+ with `scripts/edit_svg.py --help`. No Node dependency or editor
build is needed. The source lives in the skill package; Method Draw is downloaded
from its official repository to `~/.cache/d85-method-draw/<pinned-commit>/` by
default. Use `--cache-dir` for a writable alternative. The launcher checks the
archive checksum and then cached file hashes, retains the MIT license, and
does not install software globally. Use the host's normal network permission
mechanism when needed; do not replace the pinned archive with an unverified one.

For an offline/pre-downloaded setup, supply `--archive /path/to/archive.tar.gz`.
The pinned URL and SHA-256 are constants in the launcher. Failed or modified
caches must be replaced in a fresh cache directory. Initial download requires
GitHub access; once cached, the editor disables the upstream remote font catalog
and blocks external browser resource loading. Document images/fonts must be
embedded or already installed locally. The launcher rejects relative/remote
image references; embed authorized local assets into a working SVG copy first.

The launch command stays running and prints one JSON record containing
`editor_url`, `pid`, and `session_json`. Keep it running using the host's normal
terminal session or background process; do not leave the user an expired URL.
Each new session uses a fresh unpredictable URL and writes a `.svg-edit-*`
directory under the explicit output directory. Share that local URL with the
user only in their task. A browser reload starts from the input again until
finish, so use Finish before leaving. The editor warns about unsaved changes.

`status` returns `editing` until a valid SVG is saved. A complete record contains
`source_path`, `source_sha256`, `saved_path`, `saved_sha256`, and `completed_at`.
The command verifies saved bytes and exits with an error on hash mismatch. The
saved file is `<source-stem>-edited-001.svg`, increasing without overwriting an
existing revision. Original and generated build scripts remain untouched.
Double-click a grouped item to enter it, click its text, and use the Content
field to change wording. Press Escape to leave a group before selecting another
material. Background decorations baked into an image cannot move independently.
Failed saves keep the session editable; retry Finish. After a successful finish,
the canvas is disabled to avoid editing an already submitted revision. Start a
new session on the saved SVG for further changes.

Method Draw is a third-party SVG editor with partial SVG support. The adapter
checks text and image content survives initial import; it is not a full visual
equivalence proof. Check font faces, clipping, masks, transforms, and multiline
text in the actual render. The source and output remain available even if a
feature is unsupported. The generated portable text prompt needs this installed
package to execute; it must not invent a launcher in text-only chat.

The adapter preserves embedded font declarations, chained transforms, and image
rendering settings. It applies two small served compatibility patches to the
pinned upstream source (empty-selection guard and disabling large-document
localStorage autosave); cached originals remain unchanged. Finish is the durable
save action. The server uses an expanded connection backlog for reliable first
loads of the editor's many local assets.
