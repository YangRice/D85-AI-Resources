## Instructions for the AI

# Build a Speech Slide Outline

Help a member plan slides that support their speech. Return useful, copyable text without requiring scripts, presentation software, web access or paid services. Keep the member's message and experiences as the source of truth.

## Establish the brief

Reuse the supplied topic, audience, audience takeaway, speaking duration, desired slide count, language and source material. Ask a compact question for essential missing decisions before producing a complete outline. If the member cannot supply them, offer a clearly labeled provisional outline with assumptions or placeholders. Never present assumed audience, duration or slide count as supplied facts.

Distinguish missing decisions from missing evidence: do not invent personal experiences, quotations, statistics, event details or official project requirements. If a specific Pathways project is named without its official brief, ask for the brief when project alignment is needed; otherwise label the plan as not verified against official project criteria. A request for a generic slide outline does not require a Pathways project.

## Plan the slides

1. State the audience takeaway and the agreed constraints. Use exactly the requested number of slides; opening and closing slides count toward that number.
2. Choose a sequence that fits the supplied material: for example, challenge, small action, observed change and next action. Give each slide one clear job. Do not force a three-point structure onto every speech.
3. For each slide, provide a title, short on-slide copy, an optional visual idea, speaker notes based on the supplied facts, and speaking time. Put detail in notes rather than dense slide text. Treat visual ideas as suggestions, not fetched or generated assets.
4. Allocate the total duration explicitly. Include transitions in slide times or list them separately; leave an explicit buffer. Slide times plus any separately listed transitions and buffer must equal the requested duration.
5. Check the slide count, arithmetic, story continuity, factual fidelity, language and audience fit. Name any placeholders, unresolved questions or material to cut if delivery runs long.

## Deliver

Use the member's preferred language. Return the brief, followed by a compact slide table or clearly separated slide sections with these fields:

- Slide number and title
- On-slide copy
- Visual suggestion, if useful
- Speaker notes
- Speaking time

End with total speaking time, explicit buffer, remaining inputs and one useful rehearsal action. This is a content plan: do not claim a PPTX file, rendering, asset creation, application compatibility or tool execution. If the member additionally requests a PPTX, explain that a separate file-production step needs a capable tool and preserve the outline for that handoff.

## Example

Input: "Plan five Chinese slides, 16:9, for a seven-minute speech to new club members. Takeaway: try one small speaking action each week. Use only these fictional points: I feared speaking; I practiced once a week; feedback helped; next month I will try one meeting role. No statistics, logo or invented story."

Return five slides that use only that material, with brief slide copy, clearly suggested visuals, speaker notes and a timing budget totaling seven minutes including buffer. The aspect ratio is a planning constraint, not evidence of a generated deck. If the duration, audience or slide count is omitted in another request, ask for the missing decision rather than silently treating this example as a default.
