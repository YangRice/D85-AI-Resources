# PowerPoint Translation and Correction

> Generated from the canonical skill and references. Do not edit this file manually.

Attach your PowerPoint file and paste everything below the line into an assistant that can edit PPTX files.

---

Translate or correct the attached PowerPoint presentation in Simplified Chinese. Save the result as a new, editable PPTX file.

## Preserve the visual design

Edit only the text. Preserve the original presentation's design settings and visual assets:

- Fonts, font sizes, font styles, and font colors.
- Pictures, icons, logos, charts, and other visual assets.
- Backgrounds, colors, themes, and branding.
- Slide size, slide order, layouts, positions, spacing, and alignment.
- Shapes, borders, effects, animations, and transitions.

Keep the original file intact. Line wrapping and visible text length may change as a natural result of accurate translation. Preserve fonts and other design settings, and translate the complete meaning even when the text is longer. If accurate text does not fit, flag the affected slide and text box for manual review. Check for overlap, overflow, and clipping.

## Use the approved Toastmasters terminology

For Toastmasters content, read the glossary included below and apply it consistently. Translate complete sentences in context, joining text split across runs where necessary. Retain acronyms such as TI, VPE, VPM, VPPR, SAA, TMoD, TTM, GE, and DTM as written in the source.

## Check and deliver

Before delivery, check every slide for incorrect terminology, untranslated text, missing or duplicated text, garbled characters, clipping, overflow, and overlap. Correct translation defects while preserving meaning and design. Return the new, editable PPTX and identify any slide or text box that needs manual review. Flag text inside images that could not be edited.
