## AI 指令

# 手动编辑设计

让用户亲自编辑当前设计，再从准确保存的修改继续任务。此技能独立于头马品牌或
具体文档任务。

## 启动前先选择画布

宿主有支持所需修改的内置画布时，先询问用户选择**内置画布（推荐／默认）**或
**SVG 编辑器（Method Draw）**。本对话已有明确选择时直接沿用，不重复询问。
默认仅表示推荐选项，不代表可以跳过询问，也不能把沉默当成选择。静态图片或
文件预览不算可编辑画布。

选择内置画布时，加载最新的可编辑设计，让用户修改并取得最新保存／导出状态。
将该状态准确应用到可编辑源文件，再继续调用任务的渲染及评审检查；不要用旧布局
覆盖修改。这条路线不启动 Method Draw。内置画布无法保留所需修改时，说明限制并
提供 SVG 编辑器选项。

只有用户选择 SVG 编辑器或没有适用的内置画布时，才使用下面的 Method Draw
启动流程。用户修改文字、拖动素材后，点击 **Save and finish / 儲存並完成**，
将新的 SVG 修订直接保存到任务输出文件夹。

## 识别自然语言意图

“我要自己改文字”“我想手動編輯”“让我调整位置”“让我自己改海报”“move the
photo”“let me edit this myself”都足够。先找当前任务的可编辑源文件，不要求用户
知道格式或编辑器名称；仅在存在多个候选设计时问是哪一张。如果用户只是要求
“把标题改成 X”，直接完成修改；用户希望亲自操作时才开启编辑会话。

只有 PNG/JPEG 时，说明需要先重建独立文字及素材。把整张图片放进 SVG 不会使
图片里的文字变成可编辑文本。

## 启动与交接

脚本路径相对于本技能的安装目录解析，不依赖任务工作目录。缓存、字体、会话
生命周期与恢复方式见运行说明 (bundled in this prompt)。

```sh
python3 /absolute/path/to/edit-svg-canvas/scripts/edit_svg.py launch /absolute/path/to/design.svg --output-dir /absolute/path/to/task/output --open
```

使用宿主支持的持久进程／后台会话方式运行，用户编辑时保持服务存活。用浏览器
打开输出中的 `editor_url`，在对话中保留 `session_json` 路径。Codex 可用浏览器
面板，WorkBuddy 等宿主可用普通浏览器。告诉用户：“可以改文字、拖动素材；完成后
点击 Save and finish，再回到这里说『继续』。”

用户返回后运行：

```sh
python3 /absolute/path/to/edit-svg-canvas/scripts/edit_svg.py status /absolute/path/to/session.json
```

只有 `state: complete` 且哈希校验成功才算完成。用 `saved_path` 作为新源文件；
不要运行会覆盖用户修改的旧构建脚本。`editing` 表示尚未保存完成。交接或取消后
仅停止本会话服务。

保存只交回 SVG；调用任务决定是否导出 PNG/PDF 或继续其他流程。海报任务须从
该文件重新渲染，并重复视觉、受保护素材、二维码及独立评审检查。保存不会自动
给代理发消息、调用图像模型或发布作品。

## 能力与限制

Method Draw 路线需要 Python 3.10+、本地端口权限，首次使用需要联网或已验证的缓存／归档。
保留原文件，另存修订。明确拒绝不支持的活动内容和外部资源，不静默删除。
位图背景仍是位图，转曲文字不能按文字编辑。检查导入及保存后的实际渲染与字体。
宿主无法启动服务时，说明缺失能力并提供手动交接。纯文字便携提示词不包含可执行
技能包。未在 WorkBuddy 内实测，不得称已验证其自动发现或编辑流程。

# 本地 Method Draw 运行说明

需要 Python 3.10+；执行 `scripts/edit_svg.py --help` 查看参数，不需要 Node 或
构建编辑器。首次从官方仓库下载固定版本到 `~/.cache/d85-method-draw/<commit>/`；
可用 `--cache-dir` 指定可写缓存。核对归档及缓存文件哈希、保留 MIT 许可，
不全局安装。联网权限使用宿主正常机制，不替换为未经验证的下载。

离线或预下载时使用 `--archive /path/to/archive.tar.gz`。固定 URL 与 SHA-256
见脚本常量；缓存损坏时改用新的缓存目录。首次下载需要 GitHub，缓存就绪后
停用上游远程字体目录并阻止浏览器外部资源请求。图片及字体需要内嵌或本机已安装。
相对／远程图片会被明确拒绝；先将获准使用的本地素材嵌入工作副本。

启动后进程持续运行，输出包含 `editor_url`、`pid`、`session_json` 的 JSON。
通过宿主的终端／后台会话保活，不能给用户已失效的链接。每次会话具有独立随机
URL，在输出目录建立 `.svg-edit-*` 记录目录。本地链接仅交给当前任务用户。
完成前刷新会从输入文件重新开始，因此离开前点击完成；页面会提示未保存修改。

`status` 在保存前返回 `editing`；完成记录包含 `source_path`、`source_sha256`、
`saved_path`、`saved_sha256`、`completed_at`。脚本重新验证文件字节，哈希不符
时返回错误。文件名为 `<原名>-edited-001.svg`，序号递增且不覆盖已有修订。
失败时保持可编辑，可重试；成功后禁用画布，避免继续修改已交回的版本。需要再改，
以已保存的 SVG 开新会话。交接后停止对应进程即可。

双击群组进入，再点选其中的文字，使用 Content 栏修改内容。切换其他素材前按
Escape 离开群组。背景图片里已经烘焙的装饰不能单独移动。

Method Draw 并非支持所有 SVG 特性；适配器检查初次导入的文字与图片内容，但不
代表完整视觉一致性验证。检查实际渲染中的字体、裁切、蒙版、变换和多行文字。
即使不兼容，保留源文件及输出。纯文字便携提示词仍需要安装本技能包才可执行；
不能在纯聊天环境中假装已启动编辑器。

适配器保留内嵌字体、连续变换和图片渲染设置。仅对服务返回的上游脚本做两处小型
兼容修补：空选取保护、停用大文档 localStorage 自动保存；缓存原件不变。完成按钮
才是持久保存动作。服务扩大连接队列，避免首次同时加载大量本地资源时连接重置。

导入前拒绝不支持的属性及行内 CSS（如 letter-spacing），支持的简单声明转换为
表现属性。除内嵌 @font-face 外的样式表规则明确拒绝，不静默展开级联；不兼容时
禁止保存。导入后另核对文字及图像内容，这不是完整的视觉等价证明。
