# Poster Translation — Preserve Original Design

Native workflow launcher. Requires the installed `poster-image-translation-redesign` and `edit-svg-canvas` packages with their resources, plus installed `gpt-taste`. This workflow does not assess or certify Toastmasters brand compliance. This text alone cannot run image editing, independent review or the editor server.

> Use `poster-image-translation-redesign` to translate the attached poster into [target language; default Simplified Chinese], preserving its source design. Deliver the translated PNG, genuinely editable SVG and tested **Edit this poster** link together. Follow the skill's single translation/visual review round; return draft status and findings if checks fail. Disclose missing runtime capabilities.
