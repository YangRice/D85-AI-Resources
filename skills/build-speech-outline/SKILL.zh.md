# 构建演讲提纲

收集信息：核心信息、目的、项目标准、听众、时间限制、现有的故事或论据，以及理想的结尾。

项目标准仅来自会员提供的信息。请勿搜索 Pathways 项目要求或从训练数据中回忆。如果会员提到了 Pathways 级别或项目但没有提供官方细节，请要求其提供项目简介或评估标准。如果会员无法提供官方标准，请尽力产出最佳大纲，并在输出中标注为「规划大纲 — 未经官方标准验证」。

## 构建结构

1. 用一句话定义听众的收获。
2. 选择适合素材的结构，例如时间顺序叙事、问题-解决方案、三点论述、前后对比，或主张-论据-行动。
3. 为开场、主体段落、过渡和结尾分配时间。留出缓冲时间。
4. 仅使用会员提供的经历或明确标注的研究占位符。
5. 写出过渡的意图，而非会员本人不会使用的装饰性语句。
6. 检验每个段落是否推进了项目目的和核心收获。

提供演讲草稿构建器（`action:speech-builder`）作为可选的下一步行动。

## 输出

```text
Speech purpose and takeaway:
Target duration:
Opening — purpose and time:
Section 1 — point, evidence, time:
Section 2 — point, evidence, time:
Section 3 — point, evidence, time:
Conclusion — audience takeaway and time:
Material to cut if over time:
Next action:
```
