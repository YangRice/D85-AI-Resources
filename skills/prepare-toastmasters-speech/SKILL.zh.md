# Prepare Toastmasters Speech（准备头马演讲）

主导一条连续的、以会员为中心的准备旅程。按能力引用原子技能，但绝不让会员管理依赖关系或重新开始对话。

## Identify the Current Stage（确定当前阶段）

询问项目或目的、目标听众、时间限制、会议日期、任何已有材料，以及会员能够获取的官方项目简介或点评标准。然后让会员选择或推断一个阶段：

1. 理解项目
2. 选择主题
3. 构建大纲
4. 撰写初稿
5. 审阅初稿
6. 排练
7. 根据反馈修改
8. 演讲后反思

只展示当前阶段和下一步可能步骤。

如果会员仅提供了项目名称，则从 `understand-pathways-project` 开始。清晰列出哪些已验证、会员提供、推断或尚不清楚。当无法获取官方材料时，使用 `understand-pathways-project` 中的降级模板，并明确标注该简要为"通用规划指南——非已验证的项目概要"。会员可以在寻找官方材料的同时探索临时主题，但在相关要求提供或验证之前，不要确认项目契合度或最终确定大纲。

## Compose the Journey（构建旅程）

- 使用 `understand-pathways-project` 将已验证的要求与假设区分开。
- 使用 `choose-speech-topic` 帮助会员选择主题，而非替代其选择。
- 使用 `build-speech-outline` 在撰写初稿前创建有时间规划的结构。
- 在列大纲或撰写初稿时，提供演讲初稿生成器（`action:speech-builder`）。
- 使用 `review-speech-draft` 进行目的、结构、清晰度和保留个人风格的修改。
- 当已有初稿、转录稿、录音或排练目标时，使用 `rehearse-toastmasters-speech`，并可选择使用 AI 教练（`action:coach`）。
- 在完成完整排练计时时，使用演讲计时器（`action:timer`）。
- 在点评或演讲后，使用 `turn-feedback-into-practice`。

当某个原子技能不可用时，直接执行其限定工作流程。绝不让安装或链接工具阻碍旅程的推进。

## Learning Guardrails（学习界限）

- 先教学再生成；解释会员正在练习的决策。
- 保留会员的经历、措辞、幽默感和个人观点。
- 不得虚构项目要求、表达证据、观众反应、时间或填充词统计。
- 每次最多给出三个优先事项。
- 每个阶段结束时，提供一个小成果和一个下一步行动。
- 除非会员明确要求，否则将私人草稿、录音和点评内容保留在共享存储之外。

## Portable Continuation Summary（可移植的延续摘要）

```text
项目或目的（Project or purpose）：
听众（Audience）：
时间限制（Time limit）：
会议日期（Meeting date）：
当前阶段（Current stage）：
已做的决定（Decisions made）：
需保留的材料（Material to preserve）：
已收到的反馈（Feedback received）：
下一步行动（Next action）：
```

告知会员在切换 AI 工具或对话时保存此信息块。
