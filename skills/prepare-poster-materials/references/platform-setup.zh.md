# 按需设置与手动交接

只针对已选择的路线阅读。让会员配置前先检查已有能力。解释具体收益、缺少组件、费用下载或账号动作，以及无需配置的替代方案。安装、下载、服务商设置和账号权限变更需要相应授权；本指引本身不构成授权。不在聊天中收集密钥。用一个有界任务及实际输出验证，不以目录列出为证明。保留原件。

## 已有技能及图像后端

通过平台技能清单或加载入口找单个技能，再读当前说明及相关可执行内容后受控使用。缺失时用原生等价能力或手动规格继续；确有需要且会员愿意时，才提出单个安装选项，检查来源、许可、运行要求。不自动安装整套。纯文字便携提示词不包含这些包或脚本。

针对 `baoyu-image-gen`，说明需要的是位图生成后端，不意味着用户必须选择 API。优先已有授权且合适的原生工具。选择可选后端时，检查当前偏好与服务商要求、参考图支持、输出限制和额度。可复用已配置偏好；新写设置、登录或安装 Bun/npx 包属于另一个选择。凭据放平台指定的秘密设置中。不可用时，交付说明主体、参考图、画幅、文案留白和检查项的保存提示词。

## WorkBuddy 合适时才使用

[官方设计指引](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Design-Idea)描述“新建任务 → 设计创意”、Ardot 授权及对话设计、浏览器精修。先核对会员可见版本与功能。选择该路线后由会员完成账号授权；现有本地文件操作不需要此授权。构图试验可用占位图，需要素材时才生图。保存真实编辑入口，检查导出文件和可编辑文字。文档不证明当前账号可用、具备抠图或蒙版能力，或导出无损。入口缺失时使用另一已有编辑器或交接源文件和简报，不把不可用能力称作已启用。

## 希望直接访问设计时才连接 Canva

稍后导入的素材，按需交付 PNG/SVG 即可，无须 MCP。要改 Canva 对象，检查已有授权连接及工具范围。尚无连接但希望直接编辑时，查看平台连接器目录及 [Canva 官方设置指引](https://www.canva.com/help/mcp-agent-setup/)，登录和权限由会员处理。账号地区、套餐和助手影响可用性。Canva 国际版与中国版账号独立，不假设互通。Canva Dev MCP 面向应用开发，不是普通海报操作；不把自建开发应用或 OAuth 作为新手默认。

先验证读取或访问，再在获授权时用一次可丢弃设计操作验证；打开真实编辑链接，检查输出并说明不支持的操作。登录成功不证明可编辑。无法连接时，提供精确手动步骤；仅在需要经过检查的替代文件时请求导出。

## 不安装软件的抠图

已有编辑器可见去背景功能时可选该能力，也可手动选择及蒙版。Canva 用户可在自己的编辑器中打开图片、选中它，在当前界面查找图像编辑或背景移除；只有账号实际提供时才使用，可能缺失或受套餐限制。可用时修整擦除、恢复边缘，再在支持的情况下导出透明背景 PNG。缺失时不声称免费或保证可用。

无需新软件的降级路线是已有浏览器或桌面编辑器中的选择蒙版：打开原件，选主体，细修发丝和边缘，反选后在支持 alpha 的图层清除或遮住背景，再导出 PNG。使用编辑器文档中的实际控件；会员没有这种编辑器时，询问已有编辑器或设备，再指导一个具体路线，不编造菜单。明确助手尚未制作抠图，会员返回文件后再查 alpha 和边缘。选择在线服务时，说明照片将上传，先核对素材权限及导出限制。

## rembg 可选设置决策

提出设置前读抠图资源指引。它能支持本地去背景及复用模型，但增加 Python/ONNX 兼容、磁盘下载与模型许可检查。发现运行环境、包和缓存时不触发推理；只有包、没有合适缓存权重，不算完全就绪。CPU 可选，不强推 GPU。明确选择模型，按用途核实条款，运行前说明首次下载。不在发现过程中安装或下载模型。会员不愿设置时走上述手动路线。配置获授权完成后，先用可分享照片检查真实透明输出，再处理会员素材。
