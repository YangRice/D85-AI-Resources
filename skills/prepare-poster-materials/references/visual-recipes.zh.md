# 能力发现与路线

先检查当前工具、技能清单及已知安装包位置。阅读实际接口，不假设存在通用斜杠命令、终端或 `Skill` 工具。安装了包不等于渲染或账号可用。按主技能四种证据状态标记。分派任务前阅读对应资源操作指引 (`resource-playbooks.zh.md`)，仅在需要时阅读按需设置 (`platform-setup.zh.md`)。

| 日常请求 | 发现与选择 | 输入 → 输出；检查 |
|---|---|---|
| 更好的构图 | 已装 `canvas-design` 或原生版式、渲染工具 | 目的、强调点、尺寸、精确文案、可编辑性 → 实际概念稿。比较阅读顺序和间距；静态 PNG/PDF 不等于可编辑版式。 |
| 指定配色的封面或背景 | 已装 `baoyu-cover-image` 或支持参考图的图像工具 | 主体、画幅、配色、渲染、情绪、文字策略 → 图片及保存的简报。检查裁切、杂字和参考执行。 |
| 密集活动信息 | 用于信息结构的 `baoyu-infographic` | 确认的结构化内容、优先级 → 布局与风格结合的摘要。检查每项事实、字形及阅读顺序。 |
| 相似素材或参考图修改 | 优先原生图像工具，按需 `baoyu-image-gen` | A=主体、B=配色、C=构图，加实际支持的控制 → 位图变体。检查身份、肢体及受保护区域。 |
| 透明讲者素材放 Canva | 真正的分割或去背景工具、已有编辑器，再检查已装 rembg | 原照片、选定主体 → 透明 PNG。检查真实 alpha、边缘、孔洞、裁切、分辨率和身份。无须连接 Canva；新生成人物不是提取原图。 |
| 改 SVG 文字或移动照片 | 最新源文件及 `edit-svg-canvas` | 可编辑 SVG、修改及保留要求 → 保存的 SVG 新版本及可用预览。明确文字可由助手直接改；会员手动编辑走现有集成。检查字体和保存状态。 |
| 局部替换或元素合成 | 实际支持蒙版或参考图的编辑工具 | 原图、蒙版或参考用途、约束 → 修改图片。对比区域外、脸部、接触关系、光线及精确文案，披露漂移。 |
| 翻译或换尺寸 | 当前编辑器、源文件及图像理解 | 确认译文或格式 → 重新排版。检查含义、字形、完整性和导出，不只拉伸裁切。 |

## 从选择走向操作

给出有界简报：目标与格式、源文件和参考用途、精确文案、尺寸、修改及保留要求、输出位置、检查项。通过平台实际加载入口调用已装技能，或用声明的参数调用工具。保留文件、作业、编辑标识，并使用其完成接口继续。上游偏好不能覆盖会员事实、工具选择或范围。

能执行时不只给资源名或泛泛建议。没有位图后端但能渲染版式时，若符合目标，可提供明确标注的 SVG 构图研究；不声称生成了照片或调用了缺失技能。所有执行路线都缺失时，提供相关手动步骤或工具可用的简报，并说明未完成部分。

## 澄清与学习

“时间点突出，但时间可以小”尚未确定日期、时段及成组关系。即使中途修改，也先厘清这一点，再决定超大数字或新层级。明确日期替换无需重新访谈。需要教学时，用相同事实和素材比较方案，应用一项选定修改，再检查。
