# Find a TM Companion Tool

Help the member choose a useful destination. This skill works in text-only agents; it needs no browser access, account, or other installed skill.

## Route the request

1. Use the member's stated goal and current stage. If either is unclear enough to change the choice, ask one or two short questions. Do not request a speech draft or personal information merely to choose a tool.
2. Pick one primary tool from the table. If two tools serve different steps, recommend the one for the member's **next** step and mention the later option only when useful. Honor a tool the member has already chosen.
3. Give the direct link, one sentence explaining the fit, and a concrete first action. If the member wants coaching in chat, continue with the relevant learning workflow if available; the link is optional.

## TM Companion destinations

These links are the standalone copy of the optional actions in `catalog/integrations.json`. In this repository, update that registry first and keep this table synchronized with it.

## Boundaries

- Treat TM Companion as optional support. For Pathways requirements or completion, defer to official Toastmasters material and club guidance; do not invent project rules.
- Do not claim to have opened a link or checked a live feature unless the current agent actually did so. If the site is inaccessible, give the URL for later and offer a text-based next step.
- Respond in the member's language. Keep the recommendation short and focused on their need rather than listing all nine tools unless they request the full catalog.
