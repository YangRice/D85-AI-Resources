## 1. 一个原理：人为什么会被逗笑（幽默三原理）

> 来源：欧阳斌 PPT「一个原理」。一句话——**幽默不是天赋，是三条可复制的机制**。

| 原理 | 是什么 | 段子怎么用它 | 头马例子 |
|---|---|---|---|
| **① 建立优越感（Superiority）** | 听众觉得「我比这个蠢/惨的人强」，于是笑 | 把「过去的我」或「一个荒诞的群体」写成被俯视的对象 | 讲自己社死现场，听众笑的是「还好不是我」 |
| **② 逻辑矛盾 / 逻辑反转（Incongruity）** | 预期 A 突然拐到完全不搭的 B，脑子「卡一下」后释然 | 铺垫一个逻辑，结尾用另一个逻辑破它 | "我说准备好了——准备的是怎么逃跑"（语义反转） |
| **③ 压力释放（Relief）** | 紧张/禁忌被安全地说破，压力随笑声泄掉 | 把大家心照不宣但不敢说的尴尬点破 | 自嘲拖延、无效会议、职场黑话 |

- **段子四种类型**（PPT 归类）：**吐槽型段子 / 反转型段子 / oneliner（一句话梗，杨波一脉）/ 敏感型段子**。
- **头马转译**：一篇 7 分钟稿不必四样都沾，但**至少让「优越感 + 逻辑反转」同时成立**——光有反转没有优越感=烧脑不笑；光有优越感没有反转=平淡吐槽。
- **接 SRC-011**：这三条原理是「为什么好笑」的底层；SRC-011 的 Setup→Punchline 是「怎么造出来」的上层。先懂原理，再学结构，顺序别反。

## 2. 一个框架：吐槽型段子的三要素工作表（前提 + 态度 + 呈现）

> 来源：欧阳斌 PPT「一个框架」。一句话——**一个吐槽型段子必须包含三个核心元素：前提、态度、呈现（必须有，但不必说出来）**。这是写段子前先填的 worksheet。

```
前提 (Premise / 吐槽对象)
   · 你拿谁/什么事开涮，越具体越好
   ↓  +
态度 (Attitude / 你怎么看它)
   · 4 种基本态度之一：困难 / 奇怪 / 可怕 / 愚蠢
   ↓  +
呈现 (Presentation / 怎么甩包袱)
   · 把槽点具体展现出来的方式：讲故事 / 夸张 / 类比 / 拟人 / 谐音 / 歧义
```

### 2.1 前提（Premise）：越具体越好

- **前提 = 你吐槽的对象/目标**。抽象的前提逗不笑，具体的前提自带画面。
- **细化前提（往下钻）**：欧阳斌给的范例链——
  > 吐槽「婚姻困难」→ 钻到「夫妻相处」→ 再钻到「老婆难伺候」→ 再钻到「大姨妈来了」
  >
  > 越钻越具体，段子越有杀伤力。
- **经典示范（罗宾·威廉斯）**：
  > "你知道生小孩会带来什么困难吗？有了孩子以后，你就要注意自己的言行了。你不能喝醉酒走进房间说：'嘿，我们换一下角色。爸爸现在要往你身上吐一下。'"
  >
  > 前提从「养娃困难」细化到「醉酒换角色」的具体画面，笑点立刻落地。

### 2.2 态度（Attitude）：4 种基本态度

> 态度 = 你看待这个话题的**感情和动机，带负面性**。这是段子的「情绪底色」。

| 4 种基本态度 | 含义 | 头马例子 |
|---|---|---|
| **困难** | 这事太难搞、太折磨 | "我家猫比我自律，我连猫都卷不过" |
| **奇怪** | 这事不合常理、诡异 | "我们公司团建去爬山，下山比上山还像团建" |
| **可怕** | 这事让人后怕、细思极恐 | "我腿被车撞断，但获得了超能力——一下雨就疼" |
| **愚蠢** | 这事/这人蠢得可爱或可气 | "我以为发邮件撤回能撤回尴尬，结果撤回的是道歉" |

- **可派生出的其他态度**：荒诞、夸张、肉麻……（从四种基本态度延伸）。
- **⚠️ 一般没有这两种态度**：**愤怒、哀伤**。幽默的态度是「带点乐子的负面」，愤怒和哀伤会把听众推远、破坏喜感——除非你用自嘲把哀伤转成「认命式好笑」（接 SRC-011 §6 李诞悲观底色）。
- **头马转译**：写段子先定态度，态度定了，呈现方式就好选。一个素材可以同时挂多种态度（见 §3《奶茶》案例）。

### 2.3 呈现（Presentation）：把槽点甩出来的 6 种方式

> 呈现 = 把槽点**具体展现**出来的方式（即「甩包袱」的手法）。

| 呈现方式 | 怎么做 | 例子 |
|---|---|---|
| **讲故事** | 用一个小叙事承载槽点 | 超级英雄意外获得「一下雨腿就疼」超能力 |
| **夸张** | 放大生活小事制造反差 | "她们点钞一秒几千，聊天'你发了多少''发了3秒'" |
| **类比** | 把荒诞事类比成另一件荒诞事 | "无效会议像在待机，不是关机" |
| **拟人** | 给物/抽象概念赋予人的反应 | "我的拖延症像个室友，还跟我抢遥控器" |
| **谐音** | 同音不同义制造错位 | ⚠️ 见 §5 红线，必须先做引导 |
| **歧义** | 利用一词多义/连接词歧义 | "是你的人吗"可理解成「是不是人类」 |

### 2.4 框架练习（解析一段现成段子，照着填三要素）

> 欧阳斌课堂范例，用来练「拿到一段子，能拆回前提/态度/呈现」。

**段子原文**：
> "一直都想像美国大片里的超级英雄一样，经历一场意外，从而获得一种超能力。就在去年，我经历了一场意外，腿被车撞断了，但我觉得我不亏，因为我获得了一种超能力，现在一要下雨我腿就疼，老准了。"

**三要素拆解**：
- **前提**：我的腿意外骨折了。
- **态度**：可怕（"老准了"藏着细思极恐的喜感）。
- **呈现**：反差（电影英雄受伤获得酷炫能力 vs 我受伤获得"下雨腿疼"）+ 讽刺（"我觉得我不亏"）。

> **头马转译**：练幽默先从「拆别人的段子」开始，再「填自己的三要素」。填表顺序固定：**前提（越具体）→ 态度（四选一）→ 呈现（六选一）**。没态度的段子是空壳，观众闻得出来。

## 3. 一个方法论：从自己的故事里挖笑点（找情绪 → 问问题 → 开脑洞）

> 来源：欧阳斌 PPT「一个方法论」。一句话——**笑点不在远方，在你已经讲过的故事里；缺的是一套挖法**。

```
找情绪  →  问问题  →  开脑洞
(这段里我什么感受最浓？)  (对这个感受追 5 个为什么/怎么)  (如果反过来会怎样？)
```

### 3.1 操作三步

1. **找情绪**：重读你的故事稿，标出**情绪最浓的那几个点**（愚蠢/尴尬/后悔/卑微/自以为是的得意）。情绪是笑点的矿脉。
2. **问问题**：对每个情绪点连问「为什么 / 怎么做到的 / 当时怎么想的」——问题会把你逼到具体的荒诞细节。
3. **开脑洞**：把那个细节推到荒谬极点（"如果反过来呢？""如果夸张十倍呢？"），槽点就出来了。

### 3.2 案例 A：《奶茶》（欧阳斌拆解示范）

> 故事线：计划带奶茶 → 拿到手洋洋得意 → 低级错误弄丢 → 悔恨被取笑 → 放下包袱写出稿。

| 情节节点 | 挖到的态度（情绪） |
|---|---|
| 奶茶拿到手洋洋得意 | **愚蠢**（自以为是、小人得志） |
| 低级错误弄丢奶茶 | **愚蠢 + 尴尬** |
| 悔恨不迭被取笑 | **尴尬 + 内疚 + 卑微 + 后悔** |

> 同一个故事，沿「情绪 → 态度」一路挖，能长出一串段子，不是只有一个笑点。

### 3.3 案例 B：《讲的是个啥》（欧阳斌拆解示范）

> 故事线：看不上别人的幽默工作坊 → 自己做一塌糊涂 → 和小白交流发现自己的问题 → 改变态度第二次工作坊成功。

| 情节节点 | 挖到的态度 |
|---|---|
| 看不上别人的幽默工作坊 | **自以为是的愚蠢** |
| 自己做工作坊一塌糊涂 | **尴尬** |
| 小白的吐槽点醒自己 | **被戳破的卑微** |

> **头马转译**：你「当时坚信不疑、现在看很蠢」的经历，就是现成的喜剧人物（接 SRC-011 §8 Comic Hero「错的但不放弃」）。用 §2 的态度四类型给每个节点贴标签，稿子自然长出笑点。

## 4. 一个观察法：生活里哪里找段子（挖「不对劲」的地方）

> 来源：欧阳斌 PPT「挖掘让自己觉得'不对劲'的地方」。一句话——**段子素材不在书本里，在你每天觉得'这不对劲'的瞬间**。

**心法**：走路坐车刷手机时，一旦冒出「这有点怪 / 这人怎么说这话 / 这逻辑哪不对」，立刻记下来——那就是段子胚子。欧阳斌给了 5 个即抄案例：

| # | 生活场景（不对劲） | 吐槽（呈现方式） |
|---|---|---|
| 1 | **地铁广播**："感谢乘客们一路的关心和支持" | "什么时候关心你了，你也太自恋了吧？"（拟人/反问） |
| 2 | **超市海鲜促销大喇叭**：循环播放特价海鲜 | "打死我也不会在大喇叭那买海鲜，因为最先被吵死的就是那附近的海鲜。"（夸张） |
| 3 | **银行员工数钱快**：一秒数好几千 | "她们平时聊天：'你这个月发了多少钱？''发了3秒。'女员工攀比老公：'妹妹你老公好厉害，18秒！''没有没有，他也就6秒，年底才有18秒。'"（夸张+歧义） |
| 4 | **滴滴司机**："你好，请问在你定位的那里吗？" | "好奇怪，我不在定位那，难道我在定位以北15公里的沙县小吃那里？"（逻辑反转） |
| 5 | **滴滴司机**："我在路边打双闪你看到了吗？" | "这里停了这么多车都在打双闪，我哪看得到啊，我在路边眨眼睛，你看到了吗？"（类比/荒诞） |

> **头马转译（灵感捕手联动）**：这 5 个案例直接进 `inspiration-workshop.md` 的「每日 3 个」素材库——但记的不是段子本身，是「不对劲 + 我的吐槽」这对。积累 20 个「不对劲」，写稿时随便挑。
> **欧阳斌结语**：**脱口秀思维 ≈ 延伸的能力**——会找「不对劲」的人，看世界都多一层喜感，这能力溢出演讲，用到沟通、观察、写作都值钱。

## 5. 谐音梗红线（呼应 SRC-011 §13.8 / §13.9）

> 来源：欧阳斌 PPT 末页正反案例。补充 SRC-011 已有的「谐音梗扣分」结论。

- **反面案例（扣钱的谐音梗）**："从前在森林里有一只公鹿，它越跑越快越跑越快，最后变成了高速公路……"——纯谐音、无铺垫、无逻辑，听众只会觉得冷。
- **正面案例（高级的谐音梗）**："超女何洁粉丝叫盒饭，口号'何洁盒饭，一生相伴'——何洁你是不是把这句话理解错了，听成了'何洁和饭，一生相伴'？"——先用 setup 把听众领到「盒饭（粉丝名）」，再拐到「和饭」，有引导、有反转，才响。
- **判据一句话（与 SRC-011 §13.9 会议点评一致）**：**谐音梗本身不丢人，丢人的是「没有铺垫、直接反转」**。用 §2.3 的「谐音」呈现时，必须先建预期（setup），再破预期（punchline）。

## 6. 欧阳斌框架四件套（一句话记忆 + 自检清单）

**口诀**：**一个原理（为什么笑）→ 一个框架（吐槽三要素）→ 一个方法论（故事中挖笑点）→ 一个价值观（不对劲观察力）**。

写一段幽默稿前，过这张清单：

- [ ] 我的笑点至少同时成立「优越感 + 逻辑反转」之一（§1）
- [ ] 每个吐槽段子能拆回「前提（具体）/ 态度（四选一）/ 呈现（六选一）」三要素（§2）
- [ ] 态度没用「愤怒 / 哀伤」破坏喜感（除非自嘲转认命）（§2.2）
- [ ] 从自己的故事里走过「找情绪 → 问问题 → 开脑洞」（§3）
- [ ] 攒了至少 3 个生活「不对劲」素材进灵感捕手（§4）
- [ ] 用了谐音/歧义，先建预期再破预期（§5）
- [ ] 幽默服务主题、不针对具体人（全 skill 红线）

> **与 SRC-011 的衔接**：清单过完后，再把笑点按 SRC-011 §1 拆成 Setup→Punchline→Tag、按 §2 选笑话结构、按 §8 把人物立成 Comic Hero，最后回 `polish-toolbox.md` 控密度（每 30–60 秒一个笑点）、回 `champion-blueprint.md` §5 控比赛密度。
