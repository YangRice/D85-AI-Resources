## 1. 笑话的物理结构：Setup（铺垫）+ Punchline（抖包袱）+ Tag（补刀）

> 来源：Greg Dean 核心模型。一句话——**笑话 = 一个「问题」+ 一个「打破预期的解答」**。

### 1.1 两段式拆解

```
Setup（铺垫/设题）
  · 交代背景：谁、在哪、什么情境
  · 抛出一个「隐含问题」：听众的大脑会自动开始猜结局
  ↓
Punchline（抖包袱/破题）
  · 给出一个「意外但合理」的回答，打破刚才的猜测
  · 关键是「预期违背」——既出乎意料，回过头又觉得对
```

- **Setup 越干净越好**：只给抖包袱必需的信息，多一个字都是在稀释笑点、提前泄底。
- **Punchline 不解释**：笑点自己成立，一解释就「冷」。头马转译：写完笑点后那句「其实就是说……」立刻删。
- **喜剧 = 真相 + 夸张**：最稳的笑点来自「大家都经历过、但没人点破」的真实，再放大一点。编造的段子细节处必然露馅（呼应 `champion-blueprint.md` §1.3「亲身真实经历」）。

### 1.2 Joke Prospectus（写每个笑话前先填的 5 格）

| 格 | 问自己 | 头马例子 |
|---|---|---|
| **Target 对象** | 拿谁/什么事开涮 | "我那个一开会就困的领导" |
| **Angle 角度** | 我对它的真实看法是什么 | "他不是困，是在用睡眠抗议无效会议" |
| **Setup 铺垫** | 给听众什么背景 | "上周例会，他眼皮打架打了 40 分钟" |
| **Punchline 包袱** | 意外解答 | "散会他最精神——原来他是在'待机'，不是'关机'" |
| **Tag 补刀** | 还能再扎一刀吗 | "建议公司给他配个开机键" |

> 头马转译：备稿里想埋一个幽默点，先填这 5 格再写。没 Angle（真实看法）的笑话是空壳，观众能闻出来。

## 2. 三种笑话结构（按难度与效果选型）

> 来源：Greg Dean。三种结构对应不同场景，**头马 7 分钟稿里至少混用两种**才不单调。

| 结构 | 形态 | 适用 | 风险 |
|---|---|---|---|
| **Straight 直给** | Setup → Punchline（一响） | 开场破冰、快速补刀 | 最低，但用多显平 |
| **Remote 误导** | Setup → 错答（顺杆爬）→ 正答（反转） | 中段制造"以为要讲 A 结果讲 B" | 中，错答要自然不刻意 |
| **Delayed 延迟** | Setup → 小包袱 → …… → 大包袱（真回报） | 长故事里的"攒大招"、CallBack 前摇 | 高，延迟段容易冷场，需小笑点续着 |

- **头马落地**：开场用 Straight 立住「这人能聊」；中段用 Remote 做认知反转（呼应 `material-and-tension.md` 共识→非共识）；结尾前用 Delayed 把前面埋的梗一次性引爆（接 §5 CallBack）。
- **禁忌**：Delayed 的延迟段**不能空**——用 1-2 个小 Straight 包袱吊着，否则观众走神就回不来了。

## 3. Premise 与 Angle：先找「离谱的角度」，再写笑话

> 来源：Greg Dean（Premise/Angle）+ 李诞（真诚角度）。**一个笑话的成败，80% 在 Angle 定得巧不巧。**

- **Premise（喜剧前提）**：把一件平常事推到荒谬极点——"要是我家猫真把我当室友，它会怎么对我？" 头马转译：从你的素材里挑一件「人人都忍了、但细想很荒谬」的事，做成前提。
- **Angle 必须真实**：李诞的硬纪律——**你对自己的素材得先信、先有情绪**，才能讲出让人笑的真东西。硬拗的角度观众秒懂。
- **一个 Target 出一组 Bit（段子群）**：别只写一个笑话。同一个对象（Target）写 3-5 个角度不同的笑话，串成一段，密度自然上来（呼应比赛「每 30-60 秒一个笑点」）。

## 4. Act-Out 扮演：把笑话「演」出来，而不是「说」出来

> 来源：Greg Dean。脱口秀的黄金不是"讲"段子，是"成为"段子里的人。

- **做法**：讲到别人的话/反应时，**直接化身那个人**——换语气、换姿态、换节奏，而不是「我老板当时说：……」。
- **头马转译（接 `delivery-craft.md` 手势三区/模仿）**：
  - 模仿老板：身体后仰、语速放慢、用【模仿XX】标注
  - 模仿当时的自己：缩脖子、语速快、声音虚
  - 一个 setup 里**两个人物**当场切换 = 最强的喜剧画面，且观众不用脑补
- **剂量**：一篇 7 分钟稿 Act-Out 控制在 2-3 处高光，全篇都在演 = 浮夸；一处都没有 = 念稿。
- **红线**：Act-Out 是「演人物」不是「羞辱真人」。模仿领导可以，模仿到让人觉得你在攻击某人 = 踩 NVC/鬼谷子红线。

## 5. CallBack 怎么埋（Greg Dean 经典，补本 skill 的「回收」细节）

> 本 skill `champion-blueprint.md` §6 已有「首尾闭环」标准，这里补**写稿时的埋法**。

- **埋点要轻**：前面提一句「我家的猫」，不解释、不发挥，像随口一提。
- **回收要响**：后面在完全无关的情境里，用同一个词/画面突然接回来——前面那笔「伏笔」此刻炸开。
- **双锚原则**（本 skill 已有）：开头埋 → 结尾收，是 CallBack 最简版；进阶是**中段埋 → 中段收**（小闭环）再接**开头埋 → 结尾收**（大闭环），全场有两层呼应。
- **头马落地**：`champion-blueprint.md` §6.1 的「画面/金句/数字/人物/道具」五类埋点直接复用；本层补一条——**埋点时在稿上标【埋：猫】**，回收时标【收：猫】，改稿时不丢。

## 6. 李诞写稿纪律：文本第一、真诚、量产出质量

> 来源：李诞《脱口秀工作手册》。这是**写稿侧的职业化纪律**，补 `champion-blueprint.md` 写稿四步闭环的「心法」层。

| 纪律 | 怎么做 | 头马转译 |
|---|---|---|
| **文本第一** | 先把逐字稿写对，表演是其次 | 头马常见病：练腔比练稿多。先把稿写到位再雕声音（`delivery-craft.md`） |
| **每天都写** | 写不好也要写，量是质量的母亲 | 灵感捕手 `inspiration-workshop.md` 的「每日 3 个」升级为「每日写 1 段带笑点的」 |
| **真诚是唯一技巧** | 你对自己的素材先信，观众才信 | 接 `material-and-tension.md` 三层价值——真实的情绪资产最值钱 |
| **把工作当工作** | 按时交稿、反复改、不靠灵感 | 21 天训练表 `delivery-craft.md` §21 加一条：每周至少 1 篇完整改稿 |
| **把观众当朋友聊** | 不是"演给谁看"，是"跟谁聊" | 直接灭掉「大家好我是 XX 今天讲」式开场（`efficient-speaking.md` §坡道） |
| **不讨好所有人** | 找到你的观众，不为全场鼓掌扭曲自己 | 头马比赛「人和」判断 `champion-blueprint.md` §1.2——但例会可以更小众 |

- **悲观底色也能共鸣**：李诞的喜剧观是用「笑着接受无奈」照亮听众。头马转译：**走心段可以用一点自嘲式认命**，比硬煽更有记忆点（呼应 `polish-toolbox.md` 自嘲永远安全）。
- **给别人的稿提意见**：找「哪句泄了底 / 哪句在解释笑话 / 哪个人物没立住」——这套就是模式 B/C 评估时的幽默诊断清单来源之一。

## 7. 冒犯的分寸：脱口秀本质冒犯，但头马要「说破不说骂」

> 来源：李诞（冒犯本质）+ 接本 skill `nonviolent-communication.md` / `guiguzi-persuasion.md` 红线。

- **脱口秀的冒犯**：戳破大家心照不宣、但不敢说的事——这才是高级幽默，不是骂人。
- **头马版转换**：
  - ✅ 冒犯「现象/制度/自己」："无效会议""我的拖延""职场黑话"——安全且共鸣
  - ⚠️ 冒犯「在场的某个人/某群体」：直接踩 NVC 豺狗语 + 鬼谷子伦理红线
  - ❌ 人身攻击、地域/性别/职业歧视：零容忍
- **判据一句话**：**笑完之后，被冒犯的人也觉得"确实"= 高级；笑完之后有人觉得"你针对我"= 翻车。**
- **补救**：万一现场发现冒犯翻车，按 `nonviolent-communication.md` Q&A 降温翻译法 + `debate-and-qa.md` 救场话术收。

## 8. 喜剧英雄 Comic Hero（Steve Kaplan）：让人物「喜」起来的底层

> 来源：Steve Kaplan。这是**故事工程的人物层**，补 `champion-blueprint.md` 故事工程的「人物弧光 / 内外冲突」。

### 8.1 Comic Hero = Noble Fool（高贵的傻瓜）

一个让人笑、让人记住的人物，有四个特征：

| 特征 | 含义 | 头马转译 |
|---|---|---|
| **有目标** | 他清楚地想要某样东西 | 你的演讲主角（通常是「过去的你」）想要解决某个困境 |
| **有计划** | 他相信自己想出了办法 | 他采取的行动——往往听起来合理 |
| **是错的** | 但他对局势/对自己有根本性误判 | **这就是喜感来源**：观众看得到他错，他自己看不到 |
| **不放弃** | 证据全摆在眼前，他还是接着干 | 执着本身就好笑又好哭，人物立住 |

> **喜剧 vs 悲剧的分水岭（Kaplan 核心）**：悲剧的英雄是**对**的（却被毁灭）；喜剧的英雄是**错**的（却一路莽下去）。头马转译：你讲自己的失败/社死时，别把自己写成受害者——写成「当时我坚信那套歪理、撞了南墙还不信」，观众既笑又共情。

### 8.2 头马落地：把「过去的我」写成 Comic Hero

- 找一段你「当时坚信不疑、现在看很蠢」的经历 → 这就是现成的喜剧人物
- 写稿时标【人物误判：我以为 XX】让误判明确，别让观众猜
- 结尾的「成长」= 英雄终于发现自己错了——这拍既是笑点也是升华（接 `champion-blueprint.md` 结尾三层升华）

## 9. Point of View 与 Meta-Secret：喜剧来自一个歪掉的世界观

> 来源：Steve Kaplan。补 `material-and-tension.md` 的「共识→非共识」价值提炼。

- **Point of View（世界观）**：喜剧人物看世界的方式跟大家不一样。头马转译：你的**非共识观点**（`material-and-tension.md` §6）就是你的喜剧世界观——把它交给「喜剧英雄」去演绎，比直接说教好看十倍。
- **Meta-Secret（元秘密）**：观众知道、但人物不知道的那件事，驱动全程笑点。
  - 头马例子：观众早知道「他追的姑娘不喜欢他」，只有他还以为有戏——这个秘密撑起整段喜剧
  - 用法：写稿时问「这段里，观众比我讲的那个人多知道什么？」有秘密 = 有戏；没秘密 = 平铺。
- **The Truth（真相）**：表面荒诞下那句真道理。头马转译：喜剧的落点最终要回到一个真价值（呼应比赛「普世价值升华」），否则只是搞笑。

## 10. Hero's Plan 英雄计划 + 喜剧结构线

> 来源：Steve Kaplan。把 §8 的人物接成一条**故事线**，补 `structure-and-logic.md` 故事骨。

喜剧结构线（写故事段时照这个走）：

```
① 英雄想要什么（目标）
  ↓
② 他相信自己想到了办法（计划，听起来合理）
  ↓
③ 计划撞墙（障碍，观众早料到）
  ↓
④ 他不放弃，换个歪法继续（执着 = 笑点密度）
  ↓
⑤ 真相揭开：他错了，但收获了真东西（落点 = 升华）
```

- **头马转译**：这条线和 `structure-and-logic.md` 故事骨「因遭做成（背景→冲突→行动→感悟）」几乎同构，区别只在**②的「错误计划」**——故意让主角带一个误判进场，喜感就出来了。

### 12.1 三种反转（李长苏原话提炼）—— 把「反转」拆到可执行

会议主持人复盘时印象最深的是：**语义的反转 · 语境的反转 · 状态的反转**。这是对 `champion-blueprint.md` §5「三段式反转」的**精细 taxonomy**，写稿时逐一体检：

| 反转类型 | 是什么 | 头马例子 |
|---|---|---|
| **语义的反转** | 同一个词/同一句话，意思突然拐弯 | "我说'我准备好了'——准备的是怎么逃跑" |
| **语境的反转** | 把场景突然换掉，预期落空 | 前面在讲公司，突然切到"在我妈面前我还是那个怂样" |
| **状态的反转** | 人物状态/情绪突然翻转 | 刚说"我赢了"，下一句"赢得是住院床位" |

- **用法**：写完一段幽默，过这三行——「我这处反转，算语义/语境/状态哪一种？三种我至少用到了几种？」三种混用 = 层次丰富；全篇只有语义反转 = 单薄。
- **接 §2 三种笑话结构**：Remote 误导 / Delayed 延迟 的「意外」本质上就是靠这三种反转之一实现的；本表给你**写的时候往哪使力**的清单。

### 13.2 核心原理：制造预期，打破预期

> 录屏 t≈3840s 的总结页，全课总纲。

```
听众以为你去 A → 但你去了 B，而且 B 还说通了
```

三种破框方式（对应 §12.1 的三种反转）：

| 破框方式 | 李长苏课上说法 | 操作要点 |
|---|---|---|
| **① 语义破框** | 同词/同句意思突然拐弯 | 利用一词多义、同音、连接词歧义；但**连接词歧义需先做引导**，否则会变成谐音梗扣分（见 13.8 会议点评） |
| **② 语境破框** | 场景突然换掉，预期落空 | 铺垫的语境设定必须严谨，前后逻辑一旦矛盾，包袱就抖不响 |
| **③ 状态改变** | 表达方式/情绪突然反差 | 不改变内容，改变语气、语速、情绪、肢体；反差越大，效果越好 |

- **头马转译**：这三者是写幽默段子的**检查清单**。写完一段，逐句问：「这里听众的预期是什么？我用了语义/语境/状态哪一种去破？如果三种都没用，这段就是平铺直叙。」
- **接 Greg Dean**：Setup 就是「建预期」，Punchline 就是「破预期」；李长苏用中文把这套工程化语言重新包装了一次。

#### 13.2.1 技巧一 · 语义破框（SRC-011e 官方讲义 p6）

> 一句话：**同一组词，听众以为你说的是 A，其实你悄悄换成了 B。**

```
表面意思 A（听众「以为的」字面含义）
        ↕  同一个词，两个意思！
隐藏意思 B（「其实是」隐藏含义）
→ 两个意思都要说得通，笑点才成立
```

- **手法**：谐音、多义词、双关语。
- **要点**：① 利用谐音 / 多义词 / 双关语；② 同一个词在**两个意思之间制造意外**；③ 听众「上当了」，反应过来就笑了；④ **关键：两个意思都要说得通**（有一个不通 = 尬梗）。
- **头马转译**：写完一句语义梗，自问「A 意思听众会自动想到吗？B 意思站得住吗？」两者皆「是」才留。

#### 13.2.2 技巧二 · 语境破框（SRC-011e 官方讲义 p7）

> 一句话：**先用铺垫把听众领到理解 A，再揭示真相是理解 B——误解 → 真相 = 笑点。**

```
【铺垫的语境】  听众以为的 → 理解 A
        ↓（揭示真相）
【揭示的真相】  实际的   → 理解 B
误解 → 真相 = 笑点
```

- **三步**：① 前面铺垫的语境，让听众往一个方向想；② 然后揭示真相，发现完全不是那个意思；③ 听众反应过来的瞬间就笑了。
- **关键：铺垫的语境要足够让人深信不疑**（铺垫不牢 → 包袱抖不响，见 §13.9 伴娘案例）。
- **头马转译**：语境破框靠「背景信息」造预期——把背景铺进 Setup，别把真相提前漏。

> 技巧三 · **状态改变**（情绪过山车）见 §13.5。

### 13.3 段子的构成：建预期 → 破预期

> 录屏 t≈720s 起反复出现的框架页，课上所有练习都围绕这一页。

- **建预期**：让听众自动脑补 A
- **破预期**：给出 B，B 还要说得通
- 一页 PPT 上只有两个框，左边「建预期」细箭头，右边「破预期」粗箭头/色块——暗示**破预期的信息量要足够大、足够突然**

### 13.4 课上拆解的网络段子案例库

> 来源：录屏 t≈840s–1080s。李长苏用这些例子演示「建预期/破预期」怎么走。可作为头马转译的练习素材。

| 案例 | 笑点结构 | 可复用的头马转译 |
|---|---|---|
| **只有丑的谈恋爱，我们美的买空调** | 词语预期错位 | 「丑/美」的语义反转；把日常焦虑变成自嘲 |
| **洗剪吹只要 50 元** | 价格锚点反转 | 制造低价预期，再揭露「只是其中一项」 |
| **这些选手赢了的话会去小区参加比赛** | 赛事层级反转 | 把「赢了」的预期从高大上拉到接地气 |
| **《试用期》**：前男友谈婚论嫁失败，因为他女朋友不同意；注：「女朋友」是小三 | 角色关系反转 | 利用「女朋友」一词的歧义做语义破框 |
| **远嫁西北**：我以为是甘肃人、宁夏人，结果发现是伊朗人 | 地理/语音双反转 | 「西北」的语义从国内省份跳到国际方向 |
| **你愿不愿意嫁给新郎，** / **有时候愿意** | 语境错位 | 伴娘/新娘身份错位；说明**语境设定必须严谨**，否则观众会不知道笑点在哪 |
| **你们俱乐部的会长是人吗？** | 连接词歧义 | 「是人吗」可理解为「是不是人类」或「人品如何」；课堂上李长苏用它来暴露「连接词歧义若不做引导，会被当成谐音梗/误会梗」 |

> **教学红线**：李长苏对《试用期》这类涉及「小三」「前女友」的段子，在课上以「可以好笑，但要注意边界」处理；一旦有学员触及敏感人物（如 13.8 里涉及「周总理」的段子），他直接以「不予评述」打断。这对应 §7 冒犯分寸：头马演讲的幽默**不针对具体人、不踩公共敏感红线**。

### 13.5 技巧三：状态改变 = 情绪过山车

> 录屏 t≈3120s。这是整节课最有操作性的技巧之一，可立即接入 `delivery-craft.md` 的声音/肢体训练。

- **不改变内容，改变你的表达方式**
- **四个变量同时可反差**：语速、语调、情绪、肢体
- **同一个故事，用不同语气演出来，效果完全不同**
- **两种演法**：
  1. 说书人正正经经讲一个荒诞的事
  2. 荒诞地讲一个正经的事
- **关键：反差越大，效果越好**
- 配有一张「情绪波动」过山车图：情绪从高点摔到低点再弹起，标注「反差！」「反差越大，效果越好！」

头马转译（接上 `delivery-craft.md`）：
- 在稿子上标注【状态改变：快→慢 / 高→低 / 正经→荒诞】
- 7 分钟稿里用 1–2 处即可，多了会显表演过度
- 特别适合处理「本来有点沉重」的素材：用平静的语气讲荒诞，或用夸张的语气讲日常，都能出喜感

### 13.6 幽默 + 演讲：不是硬塞，是自然生长

> 录屏 t≈3000s 与 t≈3480s 两页合并。核心是如何把幽默「种」进演讲，而不是贴上去。

**硬塞段子的危险（×）**：
- 段子独立存在，跟演讲无关
- 评委觉得好笑但跑题

**自然生长（√）**：
- 笑点从演讲内容本身长出
- 删掉不影响逻辑，但会少了点什么

**三个天然入口**（t≈3480s 详细页）：

| 入口 | 用途 | 头马落地 |
|---|---|---|
| **开场 30 秒** | 用自嘲破冰，建立有趣的第一印象 | 对应 `champion-blueprint.md` 凤头，但注意**自嘲后 10 秒内必须回到主题** |
| **观点过渡处** | 从一个观点切到下一个时，用笑点做润滑剂 | 避免「好，接下来讲第二点」的硬切换 |
| **结尾回扣** | 把开头用另一种方式再说一遍 | 自然形成 CallBack，比硬 call 更高级 |

### 13.7 说书人 vs 角色（SRC-011e 官方讲义 p10）

> 录屏 t≈3600s + 官方讲义 p10。delivery / presentation 层面的切分，可直接补进 `delivery-craft.md` 的「角色扮演」训练。

| 维度 | 说书人（旁白） | 角色（扮演） |
|---|---|---|
| **视角** | 第三人称，叙述者 | 第一人称，进入人物 |
| **作用** | 交代前因后果，引导观众理解 | 让观众身临其境，增强故事感染力 |
| **幽默方式** | 反差对比 / 意外转折 / 夸张描述 | 台词设计 / 语气模仿 / 一问一答 |
| **讲义例句** | 「他当时完全不知道，接下来发生的事会让全场笑翻」（蓝框＝冷静） | 「我说：你怎么回事？他说：我才要问你怎么回事！」（红框＝情绪） |

- **一句话区分**：说书人是「讲别人的故事」，角色是「当场演给观众看」。
- **头马转译**：7 分钟稿里至少做 2–3 次「说书人 ↔ 角色」切换。一直当说书人 = 讲别人的故事，没代入感；一直当角色 = 太满、没空间给听众反应。
- **接 Greg Dean §4 Act-Out**：说书人是「叙述」，角色是「Act-Out」。讲义这四栏（视角 / 作用 / 幽默方式 / 例句）可直接当切换时的自检表。

### 13.8 平淡处加料三步法

> 录屏 t≈3720s。把幽默设计变成可操作流程，适合给会员当回家作业。

```
① 写  →  ② 找  →  ③ 加
正常写稿，不用想幽默  →  读一遍，标出平淡的地方  →  用语义/语境/状态改写加料
```

- **关键判断**：「你自己都觉得无聊的地方，就是听众会走神的地方。」
- **接 §13.2**：加料时三选一——用语义破框、语境破框、还是状态改变？
- **回家作业模板**：给会员一段 200 字的日常叙述，要求标出 3 个「无聊点」，每个点用三种破框之一改写。

### 13.9 讨论区纪要中的教学点（录屏里的隐藏干货）

> 腾讯会议讨论区 +「元宝纪要」弹出的点评，也被李长苏用来教学。本节把它们结构化，避免遗失。

1. **关于谐音/连接词歧义**（会议实录，t≈2460s）：
   > 「报答复打，谐音梗，连接词没有做引导，直接做反转，一下就知道了，这就是谐音梗扣分的原因。」
   - 头马转译：谐音梗本身不丢人，丢人的是「没有铺垫、直接反转」。先用 setup 把听众领到「连接词的一个意思」，再拐到另一个意思，才高级。

2. **关于语境设定的严谨性**（元宝纪要，t≈1020s 伴娘例子）：
   > 李长苏以「我是伴娘」为例互动测试，发现部分听众觉得不好笑；原因在于前文已明确提问对象是新娘。铺垫的语境设定必须严谨，前后逻辑一旦矛盾，包袱就抖不响。
   - 头马转译：Setup 必须让听众**唯一地**走到你预期的 A；如果 A 本身模糊，Punchline 的 B 再精彩也无效。

3. **关于敏感红线**（元宝纪要，t≈1860s 周总理段子）：
   > 李长苏指出前女友段子虽好笑，但并非因词义误解；随后有学员分享涉及「周总理」的段子，李长苏以「不予评述」直接驳回，可见触及敏感红线时果断掐断话题以规避风险。
   - 头马转译：公共人物、政治、民族、宗教是**默认禁区**；即便观众笑了，也不值得。头马舞台不是开放麦，红线优先于好笑。

4. **关于冷场复盘**（元宝纪要，t≈2340s）：
   > 李长苏引导评委对「破框」段子打分，面对大量低分反馈，他顺势点出脱口秀梗需经现场检验，借低分复盘把冷场转化成教学案例。
   - 头马转译：一个梗好不好，**现场反应是唯一标准**。没响的梗不要丢，要复盘：是预期建偏了？还是破的方向不够狠？还是铺垫太长？

5. **关于状态改变的现场示范**（元宝纪要，t≈3120s 前后）：
   > 视频中李长苏的共享音频先意气风发地表示参加比赛，紧接着话锋一转说被淘汰了。这种强烈的预期反差，正是「状态改变」技巧制造笑点的核心逻辑。
   - 头马转译：状态改变的关键不是「内容多反转」，而是**语气/情绪先扬后抑或先抑后扬**。同一句台词用两种状态演，效果差一个量级。

### 13.10 角色的幽默：台词与对话（SRC-011e 官方讲义 p12）

> 官方讲义 p12。**进入角色，让观众听到不同人的声音**——「角色」路线最可操作的落地页，可直接当对话改写模板。

| 示范 | 三段对话 | 手法 |
|---|---|---|
| **语气模仿 + 自嘲** | 「妈，我回来了！」→「你怎么这么晚才回来？」→「因为早回来您就看不到我这么帅了」 | 用家长唠叨的语气起头，反手自夸，落差出笑 |
| **一本正经的荒诞** | 「你紧张吗？」→「不紧张啊。」→「那你的手为什么在抖？」→「……哦，那是我在打摩斯密码」 | 严肃问 + 荒谬答，且答得「言之成理」 |
| **反转自嘲** | 「你准备了多久？」→「两周。」→「那为什么讲得像两天？」→「……」 | 先立「准备充分」的预期，一句打回原形 |

- **讲义诀窍**：**不同角色用不同语气、语调、甚至声音来区分**（否则观众分不清谁在说话）。
- **头马转译**：写稿时把对话段落**分行标注「谁 / 用什么语气」**，上台前各演一遍；这是 `delivery-craft.md` 声音六变量 + 分区眼神的对话版应用。
- **接 §13.7**：这一页是「角色」那一栏的操作示范；「说书人」那条线仍负责交代与推进。
