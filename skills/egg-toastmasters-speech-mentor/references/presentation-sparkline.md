# 心跳线：用「对比」驱动全场（SRC-008｜Presentation Sparkline）

> **来源**：Akeel Alleyne《Craft the Heartbeat of Your Speech: Moving Audiences Through Contrast》工作坊（17 页 PPT，2026-09-12 会员分享）+ 同场 53 分钟录音讲解。
> **原体系**：Nancy Duarte 的 **Presentation Sparkline™**（又称 Persuasive Presentation Form™），源自她对乔布斯 2007 iPhone 发布会、马丁·路德·金《我有一个梦想》等演讲的反向工程分析。Sparkline 这个词借自 Edward Tufte 的数据可视化概念。
> **在蛋导体系里的位置**：**横切层**，专治"结构没毛病但听完没感觉"。它不替代九骨架、不替代英雄之旅，而是给骨架装上**起伏**——把"平铺直叙的一条直线"变成"高低交替的心跳线"。
>
> **一句话立场**：**一场演讲的感染力，不来自信息量，来自"什么"（What Is）与"可能成为什么"（What Could Be）之间的落差被反复撕开又缝合的次数。**

### §0.0 工作坊的开场：一段"两分钟对比"的示范

现场（录音 00:56-02:47）先让全场**闭眼**，听两段平行场景。这个开场本身就是心跳线的演示——先把听众放进最低的 What Is，再翻到最高的 What Could Be：

> **🔻 第一段（What Is）**：闭上眼。你上台，也许在公司，也许在头马。你有五分钟。你准备了。上台前你还在默最后一遍。你看台下——**他们在聊天。** 一分钟过去，**还是聊天**。两分钟过去，**还是聊天**。五分钟过去，你讲完了，**还是聊天**。你很困惑，但你坐下了。
>
> **🔺 第二段（What Could Be）**：然后另一个人上台。也许是他，也许是她。**可时间好像飞起来了。** 你开始笑，你开始享受，等你回过神——七分钟已经过了。
>
> **（睁眼）** 这时候你心里冒出一个问题：**"我怎么才能变成那样？"**

**为什么这段开场有效**（工作坊共 111 秒，全场安静）：
1. **两段用同一套细节**（聊天 / 一分钟 / 两分钟 / 五分钟 / 七分钟）——**句式不换，只换结果**，落差因此最刺眼
2. **第二人称"你"**——不是讲别人的事
3. **落在问题上**（"我怎么才能变成那样"），不落在答案上——**这就是整场的坡道**
4. 结尾第 4 页那句 **"How can I be like that?"** 与第 2-3 页的对仗句形成**三页闭合**

> **蛋导用法**：任何"讲方法"的稿子，开场都可以用这个结构——**先让听众体验"失败版本"，再让他们体验"成功版本"，落差自然生成，不用解释。**

### §0.1 为什么 OREO / PREP / AREM 都不够（本工作坊的起点）

工作坊第 8 页直接点名：**"There are already so many structures out there... O.R.E.O / P.R.E.P / A.R.E.M. But your speeches still don't leave an impact."**

原因不是这些结构错，而是**它们解决的是"组织问题"，不解决"能量问题"**：

| 结构 | 它回答的问题 | 它没回答的问题 |
|---|---|---|
| OREO | 观点怎么摆 | 听众的情绪在哪一次被抬起、哪一次被压下去 |
| PREP | 论证怎么排 | 为什么听众要在乎 |
| AREM | 论点怎么堆 | 论点和论点之间有没有落差 |

**蛋导转译**：这些结构都是**一条直线**——从 A 走到 B，信息不漏、逻辑不断，但**全程同一高度**。听众听完会说"很有道理"，然后忘掉。

**心跳线要补的，是那条直线上的高低起伏。**

> 工作坊第 2-3 页用两组对仗句做了开场对比，这个对比本身就是示范：
> - **没人笑。没人笑。没人记得。**（No one laughs / No one smiles / No one remembers）
> - **我们笑了！我们哭了。时间飞快地过去了……**（We laugh! We cry. Time flies by...）
>
> 第 16 页把第 3 页原句改成未来时——**"我们将会笑！我们将会哭。时间将会飞快地过去……"**——这就是 New Bliss 的现场演示：**同一个画面，时态一变，从"抱怨现状"变成"许诺未来"。**

## §1 核心模型：心跳线（The Presentation Sparkline）

### §1.1 一句话定义

**在"现实是什么"（What Is）和"可能成为什么"（What Could Be）之间反复来回，每一次来回都把落差拉大一点，直到最后落到"新乐园"（New Bliss）。**

画出来是一条**上下起伏的折线**，像心电图：

```
  What Could Be  ╱╲      ╱╲        ╱╲         ╱──────── New Bliss
   （可能成为）  ╱  ╲    ╱  ╲      ╱  ╲       ╱
                ╱    ╲  ╱    ╲    ╱    ╲     ╱
   What Is     ╱      ╲╱      ╲  ╱      ╲   ╱
   （现实是）          ╲        ╲╱        ╲ ╱
                       └─ 落差①  落差②  落差③ ┘
```

**三条读法**（工作坊第 9-10 页）：

| 层级 | 问题 | 头马译法 |
|---|---|---|
| **What Is** | 现状哪里不对？ | 你现在的处境、你曾经的困境、大家默认接受的错误做法 |
| **What Could Be** | 如果修好了，会好在哪里？ | 你的解法、你的转变、另一种可能的活法 |
| **New Bliss** | 所有障碍都移除之后，整个局面会变成什么样？ | 结尾那块"新乐园"——不是许愿，是**已经被你的故事证明过的未来** |

### §1.2 为什么它管用（机制，不是玄学）

1. **落差产生张力**。听众心里同时装着"现在这样"和"其实可以那样"，两者之间的缝就是张力。缝越大，越坐不住。
2. **来回产生节奏**。一次落差是"信息"；六次落差是"故事"。大脑对**反复出现的模式**才有预期，有预期才有"下一拍"的期待。
3. **每次回到 What Is 都在加压**。Duarte 原话：**"每一次移动，不作为的代价就比维持现状更重一点。"**（with each movement, the stakes for not acting became greater than allowing the current reality to continue）
4. **最后必须落地，不能停在半空**。所以才有 New Bliss——**"可能成为"变成现实**的那一刻。

### §1.3 与"大区冠军蓝图"的关系（别打架）

| 蓝图工序 | 心跳线补什么 |
|---|---|
| §1.3 五维黄金选题法 | 选题的"非共识"本身就是一次 What Is → What Could Be |
| §3 六大冠军结构 | 骨架定"怎么走"，心跳线定"走的时候高低怎么变化" |
| §4.6 情节起伏节奏设计 | **同源**——蓝图讲情节起伏，心跳线讲**立场起伏**（不只情节） |
| §6.1 CallBack 首尾闭环 | CallBack 是心跳线的**最后一次落差**：开头那个 What Is，结尾以 New Bliss 形态回来 |
| §9 结尾三层升华 | 最后一层升华 = New Bliss 的显式落地 |

**判据一句话**：**蓝图保证你"走对路"，心跳线保证你"走得有起伏"。**

## §2 三个层级怎么定（工作坊第 10 页「对立矩阵」）

工作坊给了一份极简的定义表，直接可用：

| 层级 | 自问 | 合格答案长什么样 |
|---|---|---|
| **What Is** | **现状哪里不对？** | 具体、可感、听众点头："对，就是这样" |
| **What Could Be** | **修好之后，什么会变好？** | 具体、可感、听众心里"哦？" |
| **New Bliss** | **所有障碍都移除之后，整个局面会不一样到什么程度？** | 一个**画面**，不是一个道理 |

**头马范例（"准时"这个主题）**：

| 层级 | 反例（太抽象） | 正例（可感） |
|---|---|---|
| What Is | 我经常迟到。 | 我手机里那个"再睡五分钟"，每天早上要按掉四次。 |
| What Could Be | 早起会更好。 | 把闹钟放在客厅，按掉它就得走出被子——那三十秒我赢了。 |
| New Bliss | 我会变成一个自律的人。 | 半年后我在例会上第一个到，上台讲的话题是"我怎么赢回每天的第一个三十分钟"。 |

### §2.1 「找对比」三步法

工作坊第 10 页标题叫 **"Find Your Contrast: The Opposites Matrix"**（找到你的对比：对立矩阵）。操作三步：

1. **写下你的核心主张**（一句话）
2. **把它反过来写**——"如果反过来讲，成立吗？"反过来那句话就是你的 What Is
3. **问"如果障碍全部移除"**——把第 2 步的负面反过来，推到极限，就是 New Bliss

> 这与 `material-and-tension.md` §6 的**共识版 → 非共识版**是同一套手艺的两个入口：
> 那边从"大家都会说的那句"出发；这边从"你的主张"出发。**两边都能到，选一个顺手的。**

## §3 心跳线怎么画（工作坊第 12 页原版练习，头马化）

### §3.1 次数预算：7 分钟稿撕几次落差？

工作坊第 13 页提醒：**"There are too many details for 30 minutes."**（30 分钟都装不下太多细节）——**落差不是越多越好，宁可少而狠。**

| 时长 | 落差次数（What Is ↔ What Could Be 的来回） | 备注 |
|---|---|---|
| 3 分钟 | 2 次（1 次小 + 1 次大） | 只够"现状 → 反差 → 落地" |
| 5 分钟 | 3-4 次 | 例会稿的舒适区 |
| **7 分钟（比赛）** | **4-6 次** | 蓝图 §2 的凤头/猪肚/升华/豹尾各有一次主落差 |
| 10 分钟+ | 6-8 次，但必须有 1-2 次"深潜"（同一次落差讲透） | 超过 8 次听众会累 |

**硬判据**：**连续两次都没有高度变化 = 掉人区。** 一段文字如果和上一段的"高度"一样，要么删掉，要么合并进上一段。

### §3.2 定"高度"的两个动作

给每一段标高度，只有两个值：

- **🔻 低（What Is）**：讲困境、讲代价、讲那个错误的默认做法、讲"我当时不知道"
- **🔺 高（What Could Be）**：讲解法、讲转变、讲"其实可以这样"、讲那个人的反应

**标完之后连起来看**——**如果是一条直线，重排；如果是心电图，过了。**

### §3.3 一张"心跳线体检表"（改稿时逐段填）

| 段号 | 时长 | 内容摘要 | 高度 🔺/🔻 | 与上一段的落差 | 落差是否加大 | 判据 |
|---|---|---|---|---|---|---|
| 1 | | | | — | | 开场必须在 30 秒内给出第一个 What Is |
| 2 | | | | | | |
| 3 | | | | | | |
| … | | | | | | 最后一段必须是 New Bliss（🔺 且不再回落） |

**三条否决线**：
1. 前 30 秒没有 What Is → 听众不知道你在解决什么问题
2. 落差没有递增（第 3 次的缝比第 1 次还小）→ 后面撑不住
3. 结尾还回落到 What Is → **结尾讲困境 = 全场白讲**（改成 New Bliss）

## §4 心跳线与「张力五来源」的接口

`material-and-tension.md` §2 的张力五来源，是**张力的来源清单**；心跳线是**张力的排布方式**。两者互补：

| 张力来源 | 在心跳线里变成哪一次落差 |
|---|---|
| 人与自我（我跟我的较劲） | What Is = 我做不到；What Could Be = 我做到了 |
| 人与他人（关系里的误解） | What Is = 他没懂；What Could Be = 他终于懂了 |
| 人与世界（规则/时代/命运） | What Is = 世界就是这样；What Could Be = 世界本可以不是这样 |
| 人与时间（来不及） | What Is = 太晚了；What Could Be = 现在正好 |
| 人与意义（值不值得） | What Is = 这有什么用；What Could Be = 这就是意义本身 |

**用法**：先按五来源挖出素材，再用心跳线**给每次落差配上其中一个来源**。同一个来源连续出现两次 = 单调，换一个。

> **张力判据（沿用）**：**听众的情绪曲线有没有 ≥2 次明显的下压与反弹？** 只有 1 次或 0 次 = 无张力。

## §5 New Bliss：结尾为什么必须是"新乐园"

### §5.1 定义

**不是"我希望"、"我们应该"，而是把"可能成为"讲成已经成真的样子。**

Duarte 原话：**"the 'new bliss' is the 'happily ever after.' But it's not a fairytale. It's a real vision for a future that's attainable."**（新乐园是"从此幸福地生活"，但不是童话，是一个**可实现的**未来愿景。）

**关键区分**：

| 不是 | 是 |
|---|---|
| 许愿（"希望有一天……"） | 画面（"那天早上，我在例会上第一个到"） |
| 道理（"自律很重要"） | 场景（"闹钟在客厅响，我掀开被子"） |
| 我承诺（"我会努力"） | 他们已经看见（"你也能"） |

### §5.2 头马转译：New Bliss = 甜点 + 结尾三层升华的合体

| 蛋导原有概念 | 与 New Bliss 的关系 |
|---|---|
| **高效演讲的「甜点」**（`efficient-speaking.md` §2.5） | 甜点是**位置与功能**（Q&A 之后、情感最高点）；New Bliss 是**内容与形态**（把未来讲成画面） |
| **蓝图三层升华**（`champion-blueprint.md` §9.1） | 第三层 = New Bliss 的显式落地 |
| **魔力公众演讲的「结尾彩蛋」**（`magic-public-speaking.md` §7.2） | 彩蛋 = 额外惊喜（信息层）；New Bliss = 主落点（情绪层）。**先 New Bliss，再彩蛋。** |

**硬判据（沿用高效演讲那条）**：**删掉最后一段，演讲有没有损失？** 删掉没损失 = 那不是 New Bliss，那只是"谢谢大家"。

### §5.3 工作坊现场演示的"时态转换法"

第 3 页 vs 第 16 页是同一个画面的两种时态：

| | 第 3 页（现状） | 第 16 页（新乐园） |
|---|---|---|
| 句 | We **laugh**! / We **cry**. / Time **flies** by... | We **will** laugh! / We **will** cry. / Time **will** fly by... |
| 时态 | 一般现在 | 一般将来 |
| 位置 | 开场（抱怨现在没人笑） | 结尾（许诺未来大家会笑） |

**翻译成中文的实操**：**把开场的抱怨句，原封不动留到结尾，只把"现在"换成"将会"。**

- 开场：「每次轮到我上台，台下有人在看手机。」
- 结尾：「下一次我站在这里，台下还是那些人——但这次，没有人在看手机。」

**这是最省力的 CallBack 写法**：一个字不改素材，只改时态。

## §6 「对立矩阵」：反面素材不够怎么办

工作坊只在第 10 页给了一句话，蛋导把它展开成一张表——**因为会员最常卡在"我只有一个正面故事，找不到反面"**。

**做法**：把核心词填进第一列，逐行找它的反面。**每一行都能变成一次落差。**

| 维度 | 你主张的（What Could Be） | 它的反面（What Is） |
|---|---|---|
| **时间** | 现在开始 | 再等等 / 已经太晚 |
| **能力** | 我做到了 | 我做不到 / 我不配 |
| **代价** | 值得 | 白费 / 赔上别的东西 |
| **他人** | 他懂了 | 他从来不知道 |
| **规则** | 本可以不是这样 | 世界就是这样 |
| **身份** | 我是那个人 | 我一直不是 |
| **数字** | 从 0 到 1 | 又从 1 掉回 0 |

**用法**：
1. 圈出 2-3 行与你的素材最贴的
2. 每行写成一对句："**有人说____；直到那天我看见____。**"
3. 按 §3.1 的次数预算挑选，**不要全用**

## §7 与「对比五种」的分工（别混）

`magic-public-speaking.md` §6.7 的**五种对比**是**句子/段落级的修辞手法**；心跳线是**全篇级的结构模型**。

| 层 | 手法 | 粒度 | 例 |
|---|---|---|---|
| **全篇** | **心跳线** | 段落之间 | 低 → 高 → 更低 → 更高 → 新乐园 |
| **局部** | 对比五种 | 句子之间 | "你们以为我做的是选择；其实我当时没有选择。" |

**配合方式**：**每一次落差，内部至少埋一处句子级对比。** 全篇 4-6 次落差 = 4-6 处句子级对比的最小配额。

**位置铁律（沿用）**：**全篇最狠的那一处对比，放在 70%-80% 的高光位置。**

## §7.5 现场演示拆解：工作坊那段"和朋友闹掰"的临时示范

工作坊中段（录音 08:00-11:30）讲师现场用**"我和朋友冷战了"**这个题目，即兴走了一遍心跳线——这段演示比 PPT 更能说明"怎么落地"。

| 层级 | 讲师现场填的内容 | 讲法要点 |
|---|---|---|
| **What Is（现状）** | "我不开心。我生气。" | **两个短句，不加解释**。情绪说出来就够 |
| **为什么想变**（What Could Be 的动机） | "我想跟他说话。但他很烦。**每次我跟他讲，他都不听。**" | 用**具体行为**（"他不听"）替代形容词（"他很冷漠"） |
| **自我卷入**（关键一转） | "**也许我也有点错。因为我知道不全是他的错，也有我的错。**" | ⭐ **这是全段的转折点**——从"他不对"翻到"我也有份"。**没有这一句，整段是抱怨** |
| **回望好的时候**（情感最高） | "但我还是很想记得——我们刚认识的时候，我有多开心。那时候我什么都想跟他说。" | **用"那时候"作时间锚**，把 New Bliss 建立在"曾经真实存在过"上 |
| **New Bliss** | "我们还是信任彼此的。只是事情变了，因素多了，我们回不去了——或者，**我不知道怎么回去。**" | ⚠️ 这里讲师**故意没有把 New Bliss 说圆满**，而是停在"我不知道怎么回去" |

**这段演示暴露了一个高级技术（蛋导提炼）**：

> **New Bliss 不必是"完美结局"。**
>
> 上讲台的人常以为结尾必须"大团圆"。其实**"我还不知道怎么办，但我知道我不想要现在这样了"**——这也是 New Bliss。因为它把 What Is 的立场**翻过来了**：从"就这样吧"变成"我不接受"。
>
> **判据**：结尾那一刻，听众的立场有没有被翻动？翻动了就是 New Bliss，圆满不圆满是次要的。

**第二个技术**：讲师演示时**没有用"对比"这个词**，全程在讲"我怎么想"。听众反而听懂了心跳线——**因为落差是感受到的，不是被告知的**。

> **蛋导用法**：教心跳线时，**先讲一段带落差的真人故事**，再讲模型名称。反过来（先讲名词再举例）会员记不住。

## §8 头马转译四条红线

| # | 红线 | 说明 | 判据 |
|---|---|---|---|
| 1 | **New Bliss 不能是空头支票** | 许诺的未来必须**已被你这段经历部分证明过**。没证明 = 喊口号，评委扣分 | 这个未来，你有一段故事能撑住吗？ |
| 2 | **落差不能靠编** | 为造落差而虚构"我当年多惨"= 违反真实性。可以压缩、可以重组，**不能编** | 讲完敢不敢说"这是真的"？ |
| 3 | **What Is 不能变成抱怨** | 讲困境的目的是**引出落差**，不是倒苦水。抱怨超 60 秒 = 观众开始同情或反感 | 讲完这段，听众是"我懂了"还是"你好惨"？ |
| 4 | **端到端只能用一条线** | 心跳线是**一条**主线的起伏，不是两条线各起伏。双线并行时，**两条线的高度变化要同步（同时低、同时高）** | 画出来是不是一个心电图？两条不同步 = 两个演讲 |

## §9 实操：心跳线六段法（工作坊第 12 页原版练习 · 头马化）

工作坊给了一个**即兴演讲**练习，蛋导把它改成**任何稿子都能用的六段法**。

### 原版三步（第 12 页）

> **Task**: Map out an impromptu speech. **Prompt**: "When was the last time you failed?"（你上一次失败是什么时候？）
> **Steps**: ① 画心跳线 ② 用 6 个要点写下你的故事 ③ 把要点映射到线上

### 头马化六段法

**第一步：画线**（纸上横轴 = 时间，纵轴 = 高度）

```
高 ┤        ╱╲              ╱╲        ╱────
   ┤   ╱╲  ╱  ╲            ╱  ╲      ╱
中 ┤  ╱  ╲╱    ╲     ╱╲   ╱    ╲    ╱
   ┤ ╱            ╲   ╱  ╲ ╱      ╲  ╱
低 ┤╱              ╲_╱    ╳        ╲╱
   └────────────────────────────────────
    ①      ②     ③    ④   ⑤      ⑥
```

**第二步：定 6 个点**（每点一句话，不超过 12 字）

| 点 | 内容 | 高度 | 自问 |
|---|---|---|---|
| ① | **那个"本来"** | 中 | 事情原本应该是什么样？ |
| ② | **裂缝** | 低 | 第一个不对劲的信号是什么？ |
| ③ | **假装没事** | 中 | 我做了什么去掩盖它？ |
| ④ | **最低点** | 最低 | 什么时候我瞒不住了？ |
| ⑤ | **转弯** | 高 | 什么让我换了个做法/想法？ |
| ⑥ | **新乐园** | 最高 | 现在整个局面不一样在哪？ |

**第三步：映射回线上，检查两件事**
- ④ 是不是全篇最低？不是 = 高潮不够狠
- ⑥ 是不是全篇最高？不是 = 结尾回落了

### 工作坊第 13 页的四条自查（原话翻译）

| 原话 | 蛋导译法 |
|---|---|
| Start with the big idea (what is it?) | **先定大想法**——一句话说清你要观众带走什么 |
| How do you make this gap between the what is and what could be bigger? | **怎么把这个落差拉得更大？** |
| What kinds of problems can I focus on to make the audience connect more? | **挑哪些问题，听众的连接感最强？**（挑他们**也有**的问题） |
| There are too many details for 30 minutes. | **细节太多装不下**——砍。30 分钟都装不下，你只有 7 分钟 |

### 即兴题"你上一次失败是什么时候"的示范骨架

| 点 | 示范 | 高度 |
|---|---|---|
| ① | "我报了小区比赛。我以为我准备好了。" | 中 |
| ② | "彩排时，台下第一位评委在打哈欠。" | 低 |
| ③ | "我告诉自己：是空调太闷。" | 中 |
| ④ | "正式比赛，我讲到第三分钟，忘词了。整整七秒。" | 最低 |
| ⑤ | "后来我才明白：我不是忘了词，我是从来没真的记住过。" | 高 |
| ⑥ | "现在上台前我念一百遍。台下还是那些人——但这次，没人打哈欠。" | 最高 |

> ⚠️ 这份示范本身就在示范 §5.3 的**时态转换法**——① 的"我以为我准备好了"和 ⑥ 的"这次"构成 CallBack。

### §10.1 工作坊收尾的三句话（现场原话，录音 52:43-53:23）

讲师收场时只说了三句，全部围绕"从核心出发、来回摆动"：

> **第一句（核心）**：**"Our speeches will fail to connect to the audience if we do not change the structure that we use."**
> —— 如果不改结构，我们的演讲就连接不上听众。
>
> **第二句（方法）**：**"The idea is to create contrast. If you can create contrast, you can craft a heartbeat in your story."**
> —— 要做的是**制造对比**。能制造对比，你就能在故事里做出心跳。
>
> **第三句（结果）**：**"...and maybe one day you might even become a champion."**
> —— 也许有一天，你甚至会成为冠军。

**注意收尾的语法**——第 2 页的 **"No one laughs / No one remembers"** 到这里变成了：

| 页 | 句 | 时态 |
|---|---|---|
| 第 3 页（开场） | We **laugh**! We **cry**. Time **flies** by... | 现在 |
| 第 16 页（收尾） | We **will** laugh! We **will** cry. Time **will** fly by... | 将来 |

**全场 17 页，讲师把第 3 页原封不动搬到了第 16 页，只把时态从"现在"改成"将来"。**——整场演讲本身，就是一次心跳线的自我示范。

> **这是"用一个观点讲一个观点"的最高级形态**：讲 Sparkline 的那场演讲，用的就是 Sparkline。

### §10.2 从"大想法"出发再摆回两端的实操顺序（录音 51:36-52:17）

讲师最后补了一段容易被漏掉的操作顺序——**不是"从现状出发推愿景"，而是"先定核心，再往两端摆"**：

```
          先定：big idea（大想法 / 核心）
                    │
        ┌───────────┴───────────┐
        ▼                       ▼
    What Is  ←──────────→  What Could Be
    （往下摆）                （往上摆）
        │                       │
        └──── 来回摆动 N 次 ─────┘
                    │
                    ▼
              New Bliss
```

**为什么先定核心**？讲师原话是"**从核心出发**"——因为：
- **从现状出发**，容易写成"流水账 + 最后喊口号"（跟着事件走，没有主张）
- **从核心出发**，两端才有"该摆多低、该摆多高"的基准线

**蛋导译法**：**先写一句话核心，再问"这话的反面是什么"（→ What Is）、"这话实现了会怎样"（→ What Could Be）。** 这比"从开头写到结尾"快得多，也稳得多。

## §11 与四层横切层的协同

心跳线是**第五个横切层**，专管**起伏**。它与其他四层的接口：

| 层 | 管什么 | 与心跳线的接口 |
|---|---|---|
| **高效演讲** | 靶心（结果-关联-要点）与状态 | 心跳线的**第一次落差**就是"结果"的落差（现在的痛 → 讲完后的好） |
| **乔布斯** | 骨架与打法 | **大坏蛋 = What Is；常胜英雄 = What Could Be；One More Thing = 最后一次落差** |
| **魔力公众演讲** | 画面工艺（句子级） | 每一次落差内部，用 3D 五感/对话/对比把两侧都讲具体 |
| **鬼谷子** | 分寸（对谁讲到几分） | **揣 → 摩 决定 What Is 讲多深**（讲浅了没张力，讲深了伤人）；**决 = New Bliss 的行动化** |
| **心跳线（本文件）** | **起伏（段落级）** | — |

**调用顺序（五层全开）**：
**① 高效演讲定靶心 → ② 乔布斯搭骨架 → ③ 心跳线排起伏 → ④ 魔力公众演讲填血肉 → ⑤ 鬼谷子调分寸 → ⑥ 高效演讲调状态**

**口诀（v4.6 起）**：**靶心 → 骨架 → 起伏 → 血肉 → 分寸 → 状态**

## §12 改稿时的一句话总判据

**把稿子每一段标上 🔺 或 🔻，连起来看：**

- **是直线** → 重排，插入落差
- **是心电图但落差递减** → 把最狠的素材挪到后半段
- **是心电图但结尾回落** → 结尾改成 New Bliss（时态转换法）
- **超过 8 次落差** → 合并，宁少勿滥
- **每次落差都在同一维度** → 按 §6 对立矩阵换维度

**最终极的一问**：
> **听众听完，心里有没有一个"本来可以不一样"的画面？**
> 有 = 心跳线立住了。没有 = 你只提供了信息，没提供落差。

## §13 三分钟自检清单（改稿后逐条打勾）

- [ ] 全篇有**一个**（不是两个）大想法，能在 15 字内说完
- [ ] 开场 30 秒内出现了第一个 **What Is**
- [ ] 全篇落差次数落在 §3.1 的预算区间（7 分钟 = 4-6 次）
- [ ] 落差**递增**（第 3 次的缝比第 1 次大）
- [ ] 每一次落差内部有**一处句子级对比**（§7）
- [ ] 全篇最狠的对比在 **70%-80%** 位置
- [ ] 每个落差维度不同（不在同一来源上反复，§4）
- [ ] 结尾是 **New Bliss**（🔺，不再回落），且删掉它有损失
- [ ] New Bliss 是**画面**不是道理，且**已被故事证明过**
- [ ] 若用了 CallBack，有没有用**时态转换法**（§5.3）
- [ ] What Is 的段落**没有变成抱怨**（累计 ≤60 秒）
- [ ] 没有为了造落差而编造事实（§8 红线 2）
- [ ] 双线并行时两条线**同步起伏**（§8 红线 4）
- [ ] 连续两段高度相同的地方已删或已合并
