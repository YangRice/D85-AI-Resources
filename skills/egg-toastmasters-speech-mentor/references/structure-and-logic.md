# 结构与逻辑组织（内容 50% 的骨架工程）

> 触发场景：用户问"这段怎么组织""逻辑不顺""选什么结构""过渡生硬""开头怎么写""结尾收不住"，或模式 B 诊断到结构项扣分、模式 D 走到结构维度时。
> 与另外两份的分工：
> - `speech-writing-methodology.md` → 讲**叙事型备稿怎么写**（英雄之旅六阶段、四步写作法、三重境界）
> - `material-and-tension.md` §8 → 讲**五结构选型表**（素材视角，先有素材再选结构）
> - **本文件** → 讲**结构怎么选、逻辑怎么串、过渡怎么接**，覆盖叙事类之外的全部骨架与逻辑组织技术，并给诊断清单与病症处方
>
> 核心立场：**结构是观众能不能跟上的问题，逻辑是观众信不信的问题。** 结构散 = 观众走神；逻辑断 = 观众不服。
>

## 1. 结构选型总表（先选骨架，再填肉）

| # | 骨架 | 展开顺序 | 最适场景 | 时长适配 | 弱点 |
|---|------|----------|----------|----------|------|
| 1 | **英雄之旅**（起承转①转②合升） | 遭遇冲突 → 关键挫折 → 认知转变 → 情绪转变 → 破局重生 → 反思升华 | 比赛叙事、个人成长/绝境逆袭 | 5-7 分钟 | 短稿用会显得铺垫过长 |
| 2 | **三幕式** | 建立世界（1′）→ 遭遇挑战（3′）→ 解决与转变（1′） | 新手首稿、5 分钟以内 | 3-5 分钟 | 深度有限，冲不上中区 |
| 3 | **SCQA** | 情景 → 冲突 → 问题 → 答案 | 价值观传递、情感共鸣、方案引出 | 5-7 分钟 | 冲突不强烈时整篇塌 |
| 4 | **PREP** | 观点 → 理由 → 事例 → 重申观点 | 观点说服、即兴、工作汇报、方案推介 | 1-7 分钟 | 纯叙事题套上去生硬 |
| 5 | **问题解决型（2W1H）** | 是什么 → 为什么 → 怎么做 | 分析、科普、教育培训、方法论分享 | 5-10 分钟 | 容易平，要有故事撑 |
| 6 | **坡道-发现-甜点** | 精彩开场 → 三个要点 → 情感结尾 | 激励动员、主题演讲、会议发言 | 5-10 分钟 | 三个要点易写成流水账 |
| 7 | **双线平行** | 过去线 ↔ 现在线 交替推进，结尾汇合 | 同一个心魔串两段人生、前后对照 | 5-7 分钟 | 两线失衡就塌（各占 40%，汇合 20%） |
| 8 | **时间轴（Past-Present-Future）** | 过去 → 现在 → 未来 | 变化类、趋势类、成长类、展望类 | 3-7 分钟 | 没有时间轴的题材用不了 |
| 9 | **回环式（首尾呼应）** | 开场抛出一个物件/一句话/一个动作 → 中段展开 → 结尾回到它 | 比赛演讲的万能加分项，可与任意骨架叠加 | 任意 | 呼应点必须早埋，不能硬凑 |

**选型三步决策**：
1. **叙事还是说理？** 有一个真实、有转折的亲身经历 → 走 1 / 2 / 3 / 7；要讲清一个观点或方法 → 走 4 / 5 / 6
2. **有没有时间跨度？** 有 → 可叠加 8 或 7
3. **能不能找到回环点？** 能 → 无脑叠加 9，这是性价比最高的加分手段

> **不要一稿多骨架**。一篇稿子只能有一个主骨架，其余只能作为段落内部的局部手法。
> **双线平行（7）是 EGG 会员验证过的高产骨架**——《带着恐惧上台》那一稿（80 分/准小区级）用的就是"过去伤口 ↔ 当下困境"，用同一个心魔串两段人生，天然具备非共识洞察。有两次相似经历的人优先试这个。

## 1.5 分诊台·选型决策树（SRC-001｜骨往筋来）

> 这是一份**先问目的、再选骨**的三步法。拿到题目后第一步不是找骨架，是先回答"我的表达目的是什么"。

### 第一步：我的表达目的是什么？

```
            我的表达目的是什么？
                 │
       ┌─────────┴─────────┐
       ▼                   ▼
   说服大脑               打动人心
   （讲道理）              （讲故事）
       │                   │
   使用逻辑骨             使用故事骨
   （PREP §2.5）          （因遭做成 §2.5）
```

### 第二步：自检三问

| 自检问题 | 是 → 选 | 否 → 选 |
|----------|---------|---------|
| ① 我想让听众**接受一个观点**或**做一件事**吗？ | 逻辑骨 PREP | 故事骨 因遭做成 |
| ② 我想让听众**记住一个体验**或**产生共鸣**吗？ | 故事骨 因遭做成 | 逻辑骨 PREP |
| ③ 我手上有什么素材？（短的事例 vs 完整的经历） | 完整经历 → 故事骨 | 零散观点 → 逻辑骨 |

**判据冲突时**（两个问题都点头）：以 ① 为准——表达目的决定一切，素材服从目的。

### 第三步：分诊表（不替用户挑，让他自己点）

```
【分诊台】

Q1 你的表达目的是？
  □ 说服大脑（讲道理 / 给方案 / 行动号召）
  □ 打动人心（讲故事 / 传价值 / 留回忆）

Q2 你的核心素材是？
  □ 一段完整经历（有时间、地点、转折）
  □ 几个零散观点或方法

Q3 你的听众听完需要做什么？
  □ 相信我 → 逻辑骨 PREP
  □ 感受到 → 故事骨 因遭做成
  □ 立刻照做 → PREP + 行动号召
```

### 实战范例（来自「骨往筋来」PPT 第 12 页）

| 场景 | 听众听完要做什么 | 走哪根骨 |
|------|------------------|----------|
| 工作会议发言 | 同意方案 | **逻辑骨 PREP** |
| 团队项目汇报 | 通过预算 | **逻辑骨 PREP** |
| 个人故事分享 | 拉近距离 / 激励 | **故事骨 因遭做成** |
| 即兴发言被点名 | 30 秒讲完一件事 | **故事骨 因遭做成**（精炼版） |
| 工作汇报被追问 | 解释清楚决策 | **逻辑骨 PREP** |
| 说服他人支持 | 拿到资源 / 背书 | **逻辑骨 PREP** |

> **不要套错骨**。让领导批预算时讲一段"我小时候学钢琴的故事" = 失败；让朋友安慰你时甩出一段 PREP = 没感情。
> **判错骨的最常见信号**：写到一半觉得"好无聊"——99% 是因为没问 Q1，骨架和素材不匹配。

### 选型一句话总结（写到演讲卡片上）

> **「目的是说服，先抛结论；目的是打动，先抛处境。骨架错了，再多金句也救不回来。」**

## 2. 四种逻辑序（逻辑组织的底层四种，所有内容都逃不出这四种）

选定骨架后，**段落之间的推进关系**必须从这四种里明确选一种，混用会让观众觉得跳。

### 2.1 并列（横铺）
- **结构**：A、B、C 三点，彼此平级
- **适用**：列举方法、三个理由、三个故事
- **要求**：**必须排序**——要么按重要性递增（最强放最后），要么按时间，要么按认知顺序。随意排列 = 没有逻辑
- **信号词**：第一 / 第二 / 第三；一方面 / 另一方面；还有一个
- **坑**：三点平均用力。正确做法是两点轻、一点重，或一点铺垫、两点展开

### 2.2 递进（纵深）
- **结构**：表层 → 深层；现象 → 本质；我 → 我们 → 所有人
- **适用**：价值升华、认知升级、情感推进
- **要求**：每一层必须有**新的信息量**，不能是同一句话换三种说法（这是最常见的假递进）
- **信号词**：不只是……更是；往深了说；说到底
- **范例**："我不敢在会上发言"（现象）→"我怕的不是说话，是怕说完没人接"（本质）→"怕没人接，其实是怕自己不重要"（更深的本质）

### 2.3 时间（纵轴）
- **结构**：按时间推进，或过去 ↔ 现在对照
- **适用**：成长类、变化类、事件复盘
- **要求**：**删掉无意义的时间流水**。只保留有转折的时间点，"然后……然后……然后"是最大的敌人
- **信号词**：那天 / 三年后 / 直到有一天 / 现在回头看

### 2.4 因果 / 问题-解决（链条）
- **结构**：为什么 → 所以 → 怎么办
- **适用**：说服、方案、复盘、教育
- **要求**：**因果必须经得起追问**。最常见的逻辑漏洞是"相关性当因果"（我做了 A，之后 B 发生了，所以 A 导致 B）
- **信号词**：因为 / 所以 / 这就是为什么 / 于是 / 结果

**逻辑序自检**（写完后逐段问）：
> 这一段和下一段之间，是并列、递进、时间、还是因果？说不出来 → 观众也看不出来 → 这里就是逻辑断裂点。

### 2.5 故事骨·因遭做成（SRC-001｜骨往筋来）

> 与英雄之旅（六阶段）互补的**四段式叙事骨**——适合 2-5 分钟的故事类、即兴段子、个人经历分享。英雄之旅解决"完整逆袭"，因遭做成解决"一段小事的复盘"。

**四段构成（首字母简记：「因 遭 做 成」）**：

| 段 | 名字 | 任务 | 字数占比（5′稿） | 时长占比 |
|----|------|------|------------------|----------|
| 因 | **背景** Background | 时间、地点、人物、处境——把听众"扔进现场" | 15-20% | 30-45″ |
| 遭 | **冲突/高光** Conflict | 发生了什么转折、卡点、高光时刻 | 30-40% | 90-120″ |
| 做 | **行动** Action | 我做了什么（具体到能抄走的动作） | 25-30% | 75-90″ |
| 成 | **感悟** Outcome | 我学到了什么（一句可被听众带走的话） | 10-15% | 30-45″ |

**信号词节奏**（每个段都有标志性起手式，写出来观众立刻知道进哪一段了）：

```
因  → "那天……" / "几年前的一个晚上……" / "我第一次……"
遭  → "没想到……" / "就在这时……" / "突然……"
做  → "我决定……" / "于是我……" / "我深吸一口气……"
成  → "那一刻我明白……" / "后来我才懂……" / "从那以后……"
```

**情绪曲线**（与 `material-and-tension.md` §2 张力五来源配套）：

```
情绪
  ▲
  │         ╱ 成（感悟）
  │        ╱
  │    遭  ╱         ← 最高点（情绪顶点）
  │   ╱  ╲
  │  ╱    ╲ 做（行动）
  │ ╱      ╲
  │因       ╲___（回落）
  └────────────────→ 时间
```

> **判据**：故事骨的好坏，看「遭」字是否真的到了最高点。最高点不是结尾——结尾是「成」，是回收，不是高潮。

**与英雄之旅的取舍**：

| 维度 | 因遭做成（四段） | 英雄之旅（六段） |
|------|------------------|------------------|
| 时长 | 2-5 分钟 | 5-7 分钟 |
| 复杂度 | 一个事件讲透 | 跨多年的转变 |
| 学习门槛 | 低，新手第一稿就能用 | 高，要先想清"两次转变" |
| 适用 | 即兴、例会、3 分钟破冰 | 比赛、深度故事 |
| 失败模式 | 「遭」写得太轻，没有真正的高光 | 转①转②分不清 |

**新手 30 秒口诀**：

> **「因 - 遭 - 做 - 成。背景一句话，冲突写足，行动具体，感悟一句收。」**

## 3. 微观逻辑：句子与句子之间

| 问题 | 症状 | 修法 |
|------|------|------|
| 跳跃 | 上句说东，下句说西，中间缺一步 | 补上那句"桥梁句"（观众脑子里要转一下的地方，写出来） |
| 循环 | 同一意思换三种说法反复讲 | 删到只剩一句，把省下的字数给新信息 |
| 倒挂 | 先说结论还是先说故事，全篇不统一 | 演讲一律**先抛结论或先抛悬念**，不要学写作的层层铺垫 |
| 论据不支撑论点 | 讲的是 A，举的例子是 B | 每个论点后面必须问一句"这个例子能证明它吗" |
| 数字无锚点 | "提高了很多""效果显著" | 换成具体数字 + 对比（"从 47 个字到 1550 个字"） |

**一个硬规则**：**一段只讲一个意思**。一段里出现两个中心，观众两个都记不住。

> **逻辑裂缝是最贵的失分点**。《带着恐惧上台》初稿里"老公说你当初考**艺术**"，后文展开却是"**一级注册结构工程师**"——一处对不上，听众当场出戏，前面攒的信任全丢。改稿第一件事永远是查事实链，不是润色句子。

## 3.5 素材地图·生命之花 8 维度（SRC-001｜骨往筋来）

> 当用户说"我没故事可讲了"或"我的人生太无聊"，不要再光给"人生曲线法"那一条挖矿路径——同时给他**八个采掘面**。每个维度都能挖，挖到任何一维都是一个合格的演讲素材。

### 生命之花 8 维度

| # | 维度 | 经典痛点 / 泪点 / 笑点素材举例 |
|---|------|--------------------------------|
| 1 | **工作职业** | 第一次汇报被怼、升职那天、转行那天、跳槽那一刻 |
| 2 | **家庭关系** | 父母第一次说我长大了、孩子第一次叫爸妈、和伴侣的和解 |
| 3 | **健康运动** | 跑完第一个 5 公里、生病那段时间、减肥成功 / 失败 |
| 4 | **学习成长** | 拿到证书那一刻、自学一个新技能、读懂一本难书 |
| 5 | **休闲娱乐** | 一个人旅行、看演唱会、玩剧本杀、追一部剧哭崩 |
| 6 | **财务理财** | 第一次被扣工资、第一次买房、第一次月光 |
| 7 | **社交人际** | 第一次主动加好友、被陌生人温暖、和朋友大吵 |
| 8 | **精神信仰** | 顿悟那一刻、读经 / 冥想、问"为什么活着" |

### 维度使用三原则

1. **先填满 8 格再选**。每格写 1 个"这辈子和别人提过 / 没提过但忘不掉"的事——8 格里有 3 格以上能写出来，就够 10 篇演讲
2. **演讲只挖一格**。一篇稿子只从一个维度深挖，跨维度串起来 = 主题散，观众记不住
3. **不熟的格子是金矿**。能脱口而出故事的格子 = 大家都讲烂了；写不出来的格子 = 隐藏区，挖出来反而最有辨识度

### 与乔哈里窗的配合

| 维度 | 乔哈里窗区位 | 写作建议 |
|------|--------------|----------|
| 痛点（已有故事 + 已讲过） | 公开区 | 适合打比赛——故事熟练、情感真实 |
| 痛点（有故事 + 没讲过） | 盲点区 | **首选——挖出来就是大区级素材** |
| 痛点（从没感觉 + 现在回想有） | 隐藏区 | **第二首选——第一次讲反而最打动人** |
| 痛点（从没感觉 + 想也想不出） | 未知区 | 跳过，留给未来 |

> **EGG 会员最容易挖到的金矿**：第 7 格"社交人际" + 第 8 格"精神信仰"。这两格大家写不出来，但写出来就赢。

## 3.6 开启雷达·3F 记录卡（SRC-001｜骨往筋来）

> 与素材地图配套的**日常采集工具**。不要等"有灵感"再写素材——素材是被雷达扫出来的。

### 开启雷达：3 个关注点

| 关注点 | 信号词 | 出现的瞬间 | 立刻写 |
|--------|--------|------------|--------|
| **痛点 Pain** | 难受、尴尬的瞬间 | 难堪场面、被怼、犯错、出丑 | 何时何地 + 谁在场 + 一句完整对话 |
| **泪点 Tear** | 感动、鼻酸的瞬间 | 被理解、被认可、看到善意 | 时机 + 一句被击中你的话 |
| **笑点 Joy** | 忍不住笑出声的瞬间 | 段子、自嘲、意外、错位 | 那个画面 + 你笑出声的反应 |

**三档灵敏度**：
- **L1 低敏**：一天能扫到 0-1 个——你活得太赶，刻意把节奏慢 10%
- **L2 中敏**：一天 1-3 个——正常人水平
- **L3 高敏**：一天 3+ 个——演讲者必备，建议一周整理一次

### 3F 记录卡（每次扫到立刻填）

```
┌─────────────────────────────────────────┐
│  3F 记录卡 · 日期 ________              │
│                                         │
│  Fact（事）：发生了什么小事？            │
│    ─────────────────────────────────    │
│                                         │
│  Feeling（情）：当时什么感觉？           │
│    ─────────────────────────────────    │
│                                         │
│  Finding（悟）：想到了什么道理？         │
│    ─────────────────────────────────    │
└─────────────────────────────────────────┘
```

**使用规则**：
- **当天**扫到就写，**不**过夜——睡一觉细节就丢了 70%
- 每周日固定 15 分钟**整理**——挑 3 条最值钱的归档到素材库
- 一个月后回头看——你会有 12-15 条可用的演讲素材

### 与灵感捕手（inspiration-workshop.md §1）的关系

| 工具 | 维度 | 颗粒度 | 使用频率 |
|------|------|--------|----------|
| **3F 记录卡** | 事件级（具体发生什么） | 颗粒细，每日 1-3 条 | 每天 |
| **灵感捕手** | 念头级（闪过脑海的一句话） | 颗粒粗，每日 3 个 | 每天 |
| **人生曲线** | 整段人生的关键转折 | 颗粒超大，季度更新 | 每季度 |

**三件套用法**：3F 记日常 → 灵感捕手记顿悟 → 人生曲线定期回顾 → 三层一起喂"素材地图 8 维度"。

## 4. 过渡（结构看得见的部分）

### 4.1 四类过渡

| 类型 | 作用 | 范例 |
|------|------|------|
| **桥接** | 上段末句与下段首句共用同一个词/意象 | 上段末："……那扇门我终究没推开。" 下段首："**那扇门**，三年后我又站到了它面前。" |
| **提问** | 用一个问题把观众带进下一段 | "那后来呢？" / "你可能会问，这有什么了不起？" |
| **时间/空间切换** | 明确的场景跳转 | "时间跳到去年三月。" / "换个地方说。" |
| **反转让步** | 先承认再转折 | "听起来挺励志的，对吧？但真实的版本是……" |

### 4.2 禁用的机械连接词

**"接下来""然后""其次""最后""综上所述""总而言之"** —— 这些词一出现，观众就知道你在"列清单"，不是在讲故事。

**替换表**：

| 别用 | 换成 |
|------|------|
| 接下来我要讲 | （直接讲，或）"那件事之后……" |
| 其次 / 最后 | 用时间、用提问、用桥接词，或干脆靠停顿完成切换 |
| 综上所述 | "所以，回到最开始那个问题——" |
| 首先……其次……最后 | 只保留最强的那个点作为重点，其余用故事带过 |
| 然后（高频） | 直接删。想说"然后"的时候闭嘴 1 秒 |

> **最好的过渡是让观众没感觉到过渡。** 用意象、用情绪、用停顿，而不是用路标。
> 去小标题化也是同一件事：《差一点》那一稿把"周一/周二/周三"的时间标签全删，改用"差一点"主题串三段，叙事立刻流畅。

## 5. 开头 30 秒 与 结尾 30 秒（结构里性价比最高的两处）

### 5.1 开头（任务只有一个：让观众决定继续听）

**六种有效开场** + 各自的适配：

| 开场法 | 示例 | 适配 | 禁用场景 |
|--------|------|------|----------|
| **直接抛冲突** | "我被人当场辞退的那天，是腊月二十八。" | 叙事类首选 | — |
| **提问** | "你上一次，因为害怕而放弃一件事，是什么时候？" | 观点类、共鸣类 | 别问观众答不上来的问题 |
| **反常识断言** | "我做了 34 年程序员，最擅长的技能是不说话。" | 自嘲型、个人标签强 | 没有后续支撑会显得哗众取宠 |
| **场景白描** | "凌晨两点，办公室只剩下我一个人和一台还在跑的服务器。" | 氛围型、叙事型 | 别超过 3 句，会拖 |
| **数据** | "47 个字。这是我六个小时写出来的全部。" | 理性型、职场类 | 数据必须有冲击力，否则不如不用 |
| **金句开门** | "万物皆有裂痕，那是光照进来的地方。" | 主题明确、需要定调 | 别用被说烂的名言 |

**开头的三个禁止**：
1. 禁止自我介绍（"大家好，我是 XX，我今天演讲的题目是……"）——这是最浪费的 15 秒
2. 禁止铺垫背景（"今天很高兴站在这里，感谢主持人……"）
3. 禁止致歉（"我准备得不太好""有点紧张"）

### 5.2 结尾（任务只有一个：让观众记住一句，并想做点什么）

**五种收尾**：

| 收尾法 | 结构 | 适配 |
|--------|------|------|
| **回环呼应** | 回到开场的物件/那句话/那个动作，但意义已变 | 最强的收尾，与骨架 9 配套 |
| **金句收束** | 一句押全场的话，说完就停，不加解释 | 比赛演讲 |
| **行动号召** | 具体到"明天早上你可以做的第一件事" | 动员、培训、布道型 |
| **反问留白** | 抛一个问题，不回答，停 2 秒 | 走心类、思考类 |
| **画面定格** | 用一个具体画面结束，比道理更有余味 | 叙事类 |

**结尾的三个禁止**：
1. 禁止"我的演讲到此结束，谢谢大家" 之后还站着不动——说完最后一句，停 1 秒，再说谢谢
2. 禁止结尾加新信息（观众此时已经记不住了）
3. 禁止"让我们一起……"（公式化、无个人感，直接掉一个档次）

## 6. 结构诊断清单（15 条，改稿前先过一遍）

**宏观**
- [ ] 1. 全篇能不能用**一句话**说出核心信息？（说不出 = 没有中心）
- [ ] 2. 主骨架是 1-9 里的哪一种？说得出名字吗？
- [ ] 3. 段落之间的推进关系是并列/递进/时间/因果的哪一种？逐段标出来
- [ ] 4. 有没有**至少一次**明显的转折或认知反转？（一条直线到底 = 无张力）
- [ ] 5. 情绪曲线有没有 ≥2 次起伏？（判据见 `material-and-tension.md` §2）
- [ ] 6. 开头 30 秒内有没有出现冲突、悬念、或反常识？
- [ ] 7. 结尾有没有回扣开头？
- [ ] 8. 有没有**一个**明确的高光时刻，位置在 70%-80% 处？

**中观**
- [ ] 9. 三段（或三幕）的篇幅比例是否合理？（重点段应占 35%-45%）
- [ ] 10. 有没有一段塞了两个中心意思？
- [ ] 11. 每个论点后面，例子真的能证明它吗？
- [ ] 12. 有没有"然后/接下来/其次"这类机械连接词？逐个替换或删除

**微观**
- [ ] 13. 有没有观众需要"转一下才懂"的地方？补桥梁句
- [ ] 14. 有没有同一意思重复三遍的地方？删到一句
- [ ] 15. 时间/数字/专有名词是否具体？（"很久"→"三年"，"很多"→"47 个"）

## 7. 常见结构病症与修方

| 病症 | 症状 | 处方 |
|------|------|------|
| **流水账** | 按时周一五一十讲完，没有起伏 | 砍掉 70% 的经过，只留 2-3 个关键场景，其余用一句话带过 |
| **头重脚轻** | 铺垫占了 60%，高潮匆匆收场 | 铺垫压到 20%，把省下的字数给转折段 |
| **三段平摊** | 三段时间一样长，观众记不住重点 | 重点段扩到 40%，其余各 20% |
| **首尾不呼应** | 开头抛的东西结尾没接 | 回读开头，把开场那个物件/那句话在结尾用一次 |
| **论点与故事两张皮** | 先讲道理再讲个故事，两者没关系 | 让故事本身承载论点，讲完直接收，不要用道理复述故事 |
| **假递进** | 三点其实是同一句话换说法 | 砍成一点，另找两个真正不同的角度；找不到就换骨架 |
| **中间塌陷** | 开头精彩、结尾有力，中段拖沓 | 中段就是转折段——把"心理斗争"和"关键决定"写足，它自然不塌 |
| **结尾加新料** | 最后 30 秒开始讲新观点 | 全删。结尾只做两件事：呼应开头 + 落一句金句 |
| **标题与内容失联** | 《旧木箱》讲的全是优孟哭马 | 标题咬回内容，或改名。听众找不到锚点，全程在猜 |
| **双线塌一边** | 过去线讲 2 分钟，现在线 30 秒 | 两线各占 40%，汇合 20%，按秒表分配 |

## 8. 结构改造实操：一个逐段重排的例子

**改造前（流水账型，俱乐部级 68 分）**
```
1. 我从小性格内向（铺垫 1:30）
2. 上学时不敢发言（1:00）
3. 工作后开会也从不说话（1:00）
4. 两年前朋友推荐我去头马（1:30）
5. 第一次上台很紧张，讲砸了（1:30）
6. 但我坚持下来了（0:30）
7. 现在我敢说话了，谢谢大家（0:30）
```
**诊断**：六段时间均摊、无重点、无转折设计、无回环；第 6 段"坚持下来"是最大的浪费——观众想听的是"怎么坚持的"。

**改造后（英雄之旅 + 回环，小区级 85 分）**
```
开场（0:30） 反常识断言："我做了 34 年程序员，最擅长的技能是不说话。" + 回环物件埋设：手里那支笔
起（1:00）   遭遇冲突：朋友递给我一张头马例会的地址，我把它压在键盘下面（物件第一次出现）
承（1:00）   关键挫折：第一次上台，讲了三分钟，手里的笔掉在地上（物件第二次出现，转折的物理标记）
转①（1:30）  认知转变：师父一句话——"你不是不会说话，你是怕说完没人接"（心理斗争写足）
转②（1:00）  情绪转变 + 破局：第二次上台，我把笔放在讲台上没拿（物件第三次，行为变化）
合/升（1:30）高光时刻：金句 + 回环收尾——"那支笔现在还在我桌上。我不握着它了，但我知道它在。"（物件第四次，意义已变）
```
**改了什么**：① 按英雄之旅重排，砍掉流水 ② 用"笔"做回环（骨架 9 叠加）③ 把"坚持下来"展开成心理斗争 ④ 高光时刻放在 80% 处。

## 9. 冠军结构骨架对照（21 个世界冠军身上最常出现的 5 种）

> 与 `champion-techniques.md` 配套：那一份逐篇拆解，这一份只抽**可复用的骨架模式**。

| 骨架模式 | 代表冠军 | 长什么样 | 什么时候用 |
|----------|----------|----------|-----------|
| **物件回环** | 2014 Dananjaya（四个"I see something in you"）、2009 Mark Hunter（水槽） | 一个实物贯穿全场，每出现一次意义变一层，结尾落定 | 有一个对你意义特殊的实物 |
| **叩问驱动** | 2005 Lance Miller（The Ultimate Question）、2007 Vikas（The Swami's Question） | 全场围绕一个问题推进，答案在最后一句 | 有一个你自己也纠结过的问题 |
| **双身份对照** | 2013 Presiyan（Changed by a Tire）、2019 Aaron Beverly | 同一个人/同一件事的"之前 vs 之后"，或"别人眼中的我 vs 真实的我" | 有明显前后反差 |
| **多 vignette 串珠** | 2004 Randy Harvey、2024 Luisa Montalvo（37 Strangers） | 3-4 个短场景并列，靠一个主题串起来，结尾收束 | 没有单一大故事，但有一堆小瞬间 |
| **隐喻闭环** | 2022 Cyril Junior（Ndini）、2009 Mark Hunter（液态隐喻） | 一个隐喻（水/根/镜）开中场，结尾回到隐喻收 | 主题偏抽象（身份、归属、成长） |

**抄骨架不抄内容**：挑一个与你素材天然契合的骨架，把你的故事填进去。生搬硬套别人的情节，一眼就被看穿。

## 附：给蛋导的用法

改结构时，**不要重写稿子**——先按第 6 节 15 条过诊，按第 7 节找病症，然后只做三件事之一：**调顺序、砍字数、补桥梁句**。90% 的结构问题不需要重写，只需要重排。

用户拿不准骨架时，用第 1 节的**选型三步决策**直接替他定一个，不要让他自己挑九个选项——选择过载会让他卡住。定了之后说清楚"为什么是这个"，他下次就会自己选了。

备赛精修（冲小区以上）时，额外过一遍第 9 节，看看能不能套一个冠军骨架进去。
