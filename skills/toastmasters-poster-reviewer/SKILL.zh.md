# 头马海报评审

独立审核现有海报，或担任制作技能的独立质量门。本技能只评审，不修改/替换图片、不提交批准申请、不发布。阅读[品牌规则](references/brand-rules.zh.md)及[评审约定](references/production-contract.zh.md)，通用版本已内置；基准`tm-poster-brand-2026-08-v1`，Version 2.0、08/2026品牌手册。

## 证据与情境

查看实际候选图并记录 SHA-256/版本；有简报/文案、组织情境、目标尺寸、清单、原件及来源证据时使用已有资料。缺批准简报或保护素材证据时，先向用户提出具体问题，同时继续可进行的视觉品牌评审。缺文件不等于文案错误、照片未经授权或素材损坏，不得直接阻塞海报。描述或制作者保证不能替代查看实际图。

制作质量门必须由不同代理/会话执行；通用工具新开会话粘贴这些指令/规则并附图及简报，外部传输须授权。不得在制作会话模拟独立批准。无法查看图片时返回图片级BLOCKED，只提供初步发现。

先区分普通俱乐部/区域/中区/大区、企业俱乐部、Gavel或年度大区大会；核查年度大会资格，不只看标题。10月/秋季活动不适用大会自创品牌特例。区分会议话题/次要季节插画与自创组织身份。

## 五类检查

1. **品牌合规：**逐项检查适用的B01–B15并引用页码：官方标志版本、比例、来源、最终最小尺寸及留白；色板/渐变；字体层级/标准样式；照片与次要插画；获准短语/口号；Pathways关联；企业/Gavel/大会特例。照片颜色不必符合色板，建议角落位置不是强制。不得编造中文字体白名单或把证书/商品授权套到所有普通海报。
2. **文案准确：**逐区对照批准文字、日期/时间/时区、姓名、场地、会议号、链接/联系方式、拼写、翻译与完整性；OCR仅辅助，必须目视阅读。缺简报或必要事实时先请用户确认，相关内容标 PENDING_USER，不作为整体设计 BLOCKED，也不虚构文案 PASS；简报或双语文案矛盾时，先询问哪种表述才是预期事实。
3. **视觉质量：**按全分辨率及目标手机/显示尺寸检查对比、截断、重叠、层级、字符、残留生成文字/伪标志及预留区。有SVG时渲染对比PNG。可编辑指文字/素材/位置，不代表背景是矢量。独立评审未要求可编辑源时，缺SVG本身不算缺陷。
4. **保护素材完整：**有原件/来源时对照检查人像、纪实照片及官方图形；缺原件、保留证据或许可时，先询问用户是否提供/授权素材及裁切/修饰，并只索取当前疑点需要的证据。待答复标 PENDING_USER 或 UNVERIFIED，不推定未经授权或受损，不直接使整体设计 BLOCKED，也不凭相似宣称原样保留。已证实的官方标志违规仍归品牌合规。有原件时核对校验值；二维码源文件与背景生成分开。
5. **二维码完整：**解码最终整图及每个码的区域，对照原码内容及确认目的地，检查模块、静区和比例。看起来像码不算通过；无法解码或目的地未确认时，二维码项标 NOT_RUN 或 PENDING_USER，先询问原码、预期目的地或扫码确认，不以该证据缺口直接使整体设计 BLOCKED，也不虚构二维码 PASS。已证实的二维码错误单独列明修复建议。网络可达性与内容正确分开；不得未经授权访问私密邀请。无二维码标不适用。

会议/活动海报的必要会议信息须完整；有主题演讲嘉宾或分享主讲人时，核对姓名、获准介绍及准确主题。缺必要证据先询问，未解决事实标 PENDING_USER，不作为整体设计阻塞；简报已有但海报错误遗漏的信息须修改。明确无特色嘉宾时，嘉宾资料检查不适用；已确认纯文字介绍时，不强制照片。

## 结论

按约定报告。官方问题标规则ID/手册页码，实用建议单独标注。不得从扁平图片编造准确字体、印刷比例、哈希或许可。字体相似仅为观察，必要时取得字体/源文件证据才能字体项PASS。缺物理比例阻止印刷尺寸验证，不妨碍纯数字审核。许可未知不等于没有许可，作为待解决发布证据单独报告。

只有**品牌合规**可以硬性阻塞整体设计结论：无法查看实际图进行品牌评审，或适用且必要的品牌要求仍无法判断时才用 BLOCKED，明确规则、缺少的证据并提出具体品牌问题。缺批准简报、人像原件、许可记录、保留哈希、二维码解码器或确认目的地，本身不构成品牌违规，不能直接使整体设计 BLOCKED。

PASS 须已查看实际图、适用品牌检查满足且无已证实设计缺陷；不代表所有文案、来源和二维码事实均已核实。REVISE 表示已证实且可修复的缺陷。非品牌证据缺口在相应类别标 PENDING_USER、UNVERIFIED 或 NOT_RUN，先询问用户；未获答复则保留状态并继续品牌评审，不静默改为 PASS 或整体 BLOCKED。已确认的文案、视觉、素材或二维码问题列出修复建议。结论绑定 SHA-256，说明品牌/设计范围、各类别证据、修复及待答问题。

外部授权独立报告：不适用、已有证据、需要/待批准、未知。大会视觉设计可通过但品牌团队批准仍待定，不可称可发布。内部PASS绝不等于TI官方批准。保留缺证据情况，不自动发邮件。

优先建议修改文案、位置、官方素材及二维码叠加层，仅背景有缺陷才重渲染。候选改变即撤销旧结论，按新哈希重新检查五类。普通制作默认三轮未通过后交最新草稿/哈希和问题；用户明确授权改进直到达到视觉标杆时，遵循该额外迭代范围，不因默认次数放弃已授权任务。制作者交付前重算通过版本哈希。

## 可执行图片测量

具备 Python 3.10+、Pillow 和 OpenCV 时，在本技能目录使用唯一的图片评审检查器：先运行 `python scripts/check_brand.py --template`，填写实际观察，再运行 `python scripts/check_brand.py --candidate poster.jpg --observations observations.json`。格式、依赖和参考图准备见 `scripts/README.md`；`--rules` 导出手册标识和测量数据。模型查看实际图片及必要裁切，提供标志搜索区域、所有允许的参考图版本、设计色遮罩和可读文案，并记录不确定项。不得补全模糊文案，或编造字体身份、模型名称、来源和测量结果。观察文件须绑定实际导出的校验和。

检查器测量标志定位、原始几何、外观、留白、效果、数字尺寸、设计色像素、口号及营销短语；不调用 OCR 或模型 API，不需要渲染日志和字体文件。区分模型观察、实际像素测量与来源证据；其他检查无法核实时仍保留已知缺陷。缺输入或能力时，对相应工作标 BLOCKED 或 NOT RUN；无法执行时提供已准备的输入及手动路径，不虚构自动 PASS。

限定范围 PASS 不等于完整视觉/品牌 PASS 或发布授权。其余品牌类别须依共享规则进行视觉评审；确切字体、印刷尺寸、权利和批准需要各自证据。报告未分类遮罩像素、定位不确定性和弱匹配。数值阈值是工程筛查设置，不是官方品牌豁免。每个变更后的导出均须重新观察和评审；单元测试不证明所有模型或平台普遍可靠。
