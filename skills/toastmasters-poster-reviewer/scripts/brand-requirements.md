# Measurement coverage

Baseline: Brand Manual Version 2.0 Rev. 08/2026. The shared brand references
remain the canonical full review rules. `brand_rules.json` records manual
identity, palette/gradient data and copy strings used by the image checker.
`--rules` exports that data. The checker supports one observation workflow.

| Manual pages | Image-checker scope | Remaining review |
|---|---|---|
| 8–9, 12, 21 | Supplied logo-reference localization; original geometry; appearance and local alterations | Official provenance, correct asset family and visible legibility |
| 8–9, 21, 28 | Projected wordmark-height clear space and supplied foreground ink | Correct X measurement, completeness and semantic foreground classification |
| 8–9, 21 | Applicable 72px digital minimum at supplied target width | Actual print dimensions and medium-specific standards |
| 12 | Extra ink/effect screening on a corroborated uniform backdrop | Busy backgrounds, object integration and visual context |
| 14–20 | Masked RGB/Lab design-color measurements; permitted palette/blend membership | Exact press formulations, gradient recipe/opacity, dominance and contrast judgment |
| 29 | Model-read exact tagline strings and marketing phrases/count | Transcription/classification accuracy, translations and text over faces |
| 4–6, 11, 22–28 | Not measured | Voice/tone, organizational identity, badge relevance, fonts, hierarchy, photos and illustrations |
| 31, 35–44 | Not measured | Rights/approval, corporate/Gavel/conference context, sponsors, other media and distribution |

PASS applies only to requested checks and supported regions. Model observations,
pixel measurements and authentic source provenance are distinct evidence.
Missing sources do not prove a visible defect; resemblance does not establish
exact font identity. A complete visual brand review must still inspect every
applicable category using the shared rules. No script result is official approval
or release authorization. Numeric vision thresholds are engineering settings,
not manual exemptions. Print readiness and sharing rights need separate evidence.
